先为你的站点准备一把钥匙

在电脑上双击打开本文件。口令在当前浏览器中随机生成，不联网，不上传，不保存到服务器。每个新站点都应独立生成。

保存两个文件

下载 key.php下载私密口令
  1. 将上传包中的全部文件上传到网站目录，保留 .htaccess 等隐藏文件。
  2. 把刚下载的 key.php 上传，覆盖网站 install/key.php。请确认文件名没有变成 key (1).php。
  3. 打开网站的 /install/，粘贴上方口令，填写数据库和管理员信息。
  4. 安装成功后删除服务器上的 install 目录。将 INSTALL_KEY.txt 留在自己的电脑，绝不上传到网站。

如果浏览器不允许生成，请用最新版浏览器在本机打开此文件（file://），或通过 HTTPS 打开。已有站点升级无需重新安装，也无需重新生成口令。
