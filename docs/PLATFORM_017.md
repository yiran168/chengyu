# 0.17.0 新模块操作手册

本版基于 0.16.0，数据库目标 v9。下面描述已接入界面的功能，不表示真实服务账号已经联调。旧交易/会员/售后说明继续见 `COMMERCE_016.md`。

## 1. 搜索索引：后台 → 搜索索引

先到设置的检索分组选择 portable。后台索引页显示当前游标、内容数和词条数。点击“继续构建”会逐批处理，每个请求 10 条；当前页面最多连续 100 批后暂停，再点击可接着处理。关闭页面不会启动后台守护进程，已完成的游标保留。无 JavaScript 可点击单批按钮。

重建会清空旧索引并从头开始。重建完成前，前台自动使用原有元数据搜索；完成后使用倒排索引。大站在业务低峰重建，检查数据库空间和执行时间。管理员发布/编辑内容、审核译文时同步相关索引，不必每次全量重建。

索引只包含公开标题、摘要、标签及当前有效发布译文，不索引正文、付费正文、章节、私信、工单或笔记。查询时仍检查在线发布状态、原文修订、栏目与模块权限。搜索支持英文词和中日韩文字相邻二元组，不等同于语言学分词、拼音纠错、同义词或 Meilisearch/Elasticsearch。后台可切回 legacy。尚未验证十万/百万内容性能。

## 2. 课程：后台 → 课程工作台

先创建一篇文章或数字商品，设置真实的阅读/购买/VIP权限与价格，再创建课程并填入该内容 ID。课程保存后固定使用此来源，不允许随意更换造成历史购买错绑。每个来源最多一个课程。

课程可先存草稿；填入课程标题、公开说明，再创建章节。章节支持 Markdown、顺序、时长、发布状态、免费预览与一个私有资源 ID。资源需先在媒体工作台上传为私有 MP4、MP3、PDF、ZIP 或纯文本。最多 500 章节，课程侧栏暂显示最新 100 课程；较早课程可按 ID 打开。

“免费预览”明确公开本章节及其资源，不是只公开标题。不要在预览和付费章节中复用同一个私有文件，除非确实希望公开。已有公开媒体不能填入私有资源字段。

前台 `/index.php?r=courses` 为学习中心，课程详情显示章节，`r=learn&id=章节ID` 为阅读页。未购买用户只能看允许预览的章节。购买、会员资格和有效期沿用来源内容权限，成功退款后撤销对应购买权限；下架课程/章节也会重新校验。管理员/编辑可查看草稿。

登录用户可保存进度、完成标记与私人笔记。媒体暂停会填入当前位置，必须点击保存才同步到账户；不在后台自动监听学习。多设备同时编辑时后保存的旧版本会被拒绝，先刷新再合并笔记。“完成”是用户自报，不是考试、证书或防刷学时。访客购买可读已授权内容，但保存学习记录需要注册账号。

本版不是直播、HLS、转码、DRM、自动字幕、测验或证书平台。使用原生 MP4/MP3 播放器和现有 Range/对象短时链接。

## 3. 页面编排：草稿、发布、历史

原有 22 个位置与 11 种区块继续可用。后台编排页增加草稿状态和版本信息。“保存草稿”仅保存编辑状态；“发布”才更新线上 JSON。“放弃草稿”不会撤销已发布页面。

每个位置保存最近 20 次发布快照。选择历史恢复会产生一个新发布版本，保留操作审计；不是倒改版本号。当前存在旧草稿时，恢复会将它标记为过期，避免覆盖线上新内容。多人同时编辑发生冲突时先重载，对照内容后再保存，不要重复点击强行覆盖。

恢复布局只恢复结构化布局，不恢复已删除文章、媒体或站点设置。本版仍是安全区块编排，不是任意像素画布；不能执行任意 PHP、JavaScript 或第三方 WordPress 小工具。前台导航可选择课程、学习记录和客服入口，沿用原有公开/登录/VIP/认证显示条件。

## 4. 物流：后台 → 物流履约

填入已支付实物单位订单 ID、承运商代码和单号保存。沿用原订单发货检查，不给未付款、非实物或不允许再次发货的订单绕过限制。再次修改需要当前修订版本；单号改变会清除旧轨迹，避免两个包裹串单。

手工轨迹需填含时区时间，例如 `2026-09-07T10:00:00+08:00`，以及简短说明。单个运单最多 200 条人工记录。订单拥有者从订单/收据进入轨迹页；别人的账号无法查看。

需要快递100时，在交易设置中选择 kuaidi100，填写自己的 customer 与 key。key 使用现有加密设置存储。查询时勾选同意发送单号及必要手机号，再点击刷新。顺丰/丰网需填写符合渠道要求的寄件或收件手机号。请向服务商确认具体格式、开通权限与额度。

最小查询间隔默认 900 秒，可在 300–86400 秒之间调整。缺少必填手机号不会占用间隔；已发出的请求即便失败也保留间隔，防止连续请求产生费用。结果须匹配承运商和单号，网络请求返回后还要核对原修订版本。电话只随本次查询发送，不由该模块另外持久化；轨迹与单号使用站点密钥加密。

物流接口结果只作信息展示，不自动收货、退款或释放收益。人工记录和承运商记录分别标明来源。没有电子面单、多包裹、多仓、退件独立轨迹或换货差价计算。没有后台持续轮询；接口密钥与真实轨迹本轮未联调。

## 5. 账单：后台 → 账单核对

此模块与“逐单主动查支付状态”是两件事。下载你自己商户后台的账单，依据 `STATEMENT_FORMAT.md` 转成标准格式，再粘贴或上传 UTF-8 CSV。最多 2 MiB、2000 行，账期最长 31 天，金额使用未扣渠道手续费的最小货币单位整数。

导入时填写渠道、含时区的开始/结束时间。开始包含、结束不包含；同一账期、渠道与文件摘要重复导入返回原批次。核对结果区分仅账单存在、仅本地存在、金额/币种/交易号/状态/入账凭证/时间范围不一致。

处理差异前去原渠道查单核实。点击重新核对只重读当前本地记录。上传的 CSV 是不可信输入，不能据此更改订单、余额、退款或代付。此模块不自动下载四家账单，也不处理手续费、税款、汇兑、银行账户勾兑或完整会计总账。

## 6. 客服：前台 → 客服工单；后台 → 客服工单

启用支持模块后，已注册用户可创建工单，填写主题、正文及可选的本人订单 ID。访客影子账号不能冒充注册用户开工单。正常用户仅能读取本人工单和回复，管理员可在后台处理。

管理员回复后状态变为等待用户；用户回复后重新打开。用户可关闭/重开自己的工单；管理员还可标记解决和设置紧急优先级。关闭状态不允许直接回复，必须重开。回复带版本检查，重复提交键与内容绑定，网络重试不会生成重复回复。

模板仅自动填入可编辑文本，不自动发送。管理员回复会生成站内通知，不代表配置了邮件或短信。每个工单最多 1000 回复，分 50 条分页；后台模板最多 100 个。没有附件工单、多人坐席分配、SLA工时统计或外部工单平台同步。

## 7. 中英文与支付宝电脑网站支付

前台和后台语言按钮分别保存偏好，切换后台英文不会把前台一起改成英文。旧版偏好作为兼容回退；站点默认语言与可选浏览器协商沿用原设置。自定义课程名、商品文案和商家自己写的内容不会仅凭界面切换自动翻译。内容翻译仍需审核发布；自动翻译是可选外部服务。

官方支付设置新增支付宝体验 `wap/page`。wap 为手机网站支付，page 使用 `alipay.trade.page.pay` 与 `FAST_INSTANT_TRADE_PAY`；同一服务的查单、通知验签、退款与幂等逻辑继续复用。不是微信 Native，也不包括支付宝当面付、证书模式或所有产品线。切换前先确认商户签约权限并做真实沙箱/小额验收。

## 8. 界面和部署验收

新工作台复用主题颜色、焦点、表单和动画体系；课程卡片有悬停抬升与封面缩放，工作台轨道装饰使用统一曲线，系统减少动态效果偏好会关闭装饰变换。手机变为单栏，章节目录不固定遮挡内容。后台仍保留无 JavaScript 的原生提交路径。

新增后台入口及前台链接已接入现有导航，没有放只显示菜单却没有控制器的按钮。正式上线按 `ACCEPTANCE_017.md` 逐项验证，尤其是自己主机上的原生 PDO、目录保护、HTTPS、公网通知和外部服务条件。
