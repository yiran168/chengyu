## 安装及容量

下载 upload.zip，解压后上传包内文件到站点根目录；先用本地 DEPLOY_PREPARE.html 生成独立安装验证文件，私密口令留在本地。数据库在主机面板先建立，安装程序创建业务表。旧站保留 app/config.php、原 secret、数据库和 storage，按 UPGRADE.md 覆盖升级。

2GB 网站空间与 1GB 数据库空间分别计量，不能互相替代。保留媒体、临时分片、错误日志和备份的空间余量；后台配置上传配额和备份保留数量。真实配额从主机面板读取，不把服务器整盘空闲容量当成账号剩余空间。源码运行时不要求 Composer、Node、Redis、SSH 或常驻进程。

安装页及后台“系统”读取实际 PHP 上传、POST、内存、执行时间等数值。扩展检测和真实事务检测通过后，仍需验证站点 TLS、目录保护、邮件、外部接口和真实支付回调。自动资金任务需要定时触发；无计划任务时使用后台操作，不能假装自动执行。

## VPS 和备份恢复

有宝塔 / 1Panel 等面板：创建 PHP 站点、数据库和证书，按随包模板合并服务器规则。无面板的新 VPS 提供 deploy/install-vps.sh 与 Nginx / Apache / Caddy 示例；本轮做语法检查，不宣称已装机、改防火墙或签发证书。

无 SSH、无远程数据库连接的主机不能直接从本地恢复生产库。使用独立同类型数据库环境验证加密副本，再通过面板 SQL 导入与 FTP 迁移；保留主机面板原生备份作为恢复路线。详见 BACKUP_RECOVERY.md。
