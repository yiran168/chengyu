## 免费主机使用方式

上传包内文件直接放进站点根目录，保留隐藏文件和目录保护规则。新站访问 `/install/`；完整包里的私有安装口令只在本地保存。旧站保留 `app/config.php`、`secret`、数据库与全部 `storage/`，按 `UPGRADE.md` 升级，不重装。

运行时不需要Composer、Node、Redis、SSH或常驻进程。索引可通过后台分批构建，工单/课程/手工物流用普通HTTP请求即可。官方支付、物流查询、翻译和对象存储仍需要服务账号、HTTPS和出站网络；真正自动推进资金任务需要定时触发，否则使用后台按钮。

## VPS，有面板或无面板

已有宝塔/1Panel等面板：建立PHP站点、数据库和证书，按模板合并Nginx/Apache保护规则，不运行“新机安装脚本”覆盖已有环境。Caddy示例同样须检查PHP-FPM socket与实际目录。

无面板全新VPS提供 `deploy/install-vps.sh` 和对应服务模板。本次只做脚本语法检查，未装机、改防火墙或申请证书。先阅读脚本、备份原配置，用专用低权限站点用户部署，不把教程默认路径当作所有发行版的保证。

## 0.18.0 外置搜索与恢复特别说明

Meilisearch 是可选独立服务。普通免费虚拟主机不需要安装它才能运行本站，继续使用本地检索；要启用远程模式，需你另有实例，并通过有效公网 HTTPS/443 提供专用索引。本程序不直接连接内网或 7700 端口，避免后台配置成为内网探测入口。

恢复保险库可以在站点后台创建、下载受体积和时间限制的加密副本。恢复工具不开放公网 HTTP 入口。蓝队云官方同时说明数据库只支持面板在线管理，不支持远程连接，连接地址为 localhost/127.0.0.1。因此无 SSH 主机不能假定从本地直接连生产数据库恢复；需先在独立同类型数据库环境中恢复并验证，再按服务商面板 SQL 导入及 FTP 上传流程迁移。没有该环境时保留原生面板备份作为恢复路线。详见 `BACKUP_RECOVERY.md`；本轮没有在两家主机实际执行这些步骤。
