# 前后台运营与外观设置

版本 0.17.0。站点先安装，再由自己创建的管理员登录 `/admin`。权限判断在服务端，普通用户不能通过直接输入后台网址获取管理权限。

## 1. 首次配置

站点设置先填写名称、简介、站点标识、联系方式和主机鸣谢；检查隐私/服务/退款说明，不能把默认条款当作适合自己业务的法律文件。新站先限制注册，保留只用于验收的账号。初始化示例可以修改或停用，价格和商品资源都应逐项检查。

系统页检查运行时、数据库、上传限制、存储和 HTTPS。后台不能为你安装 PHP 扩展、绑定域名或调整主机证书。SMTP 找回需要实际成功发出并收到邮件，保存配置成功不算验证完成。

## 2. 外观与动画

「外观」有 Tide、Dusk、Paper、Graphite、Citrus 五类主题，明亮/深色/跟随系统，以及关闭/磨砂/棱镜/流体玻璃。玻璃模糊和圆角、动画时长与曲线、悬浮位移、滚动显现、背景光、粒子、纹理与阅读进度等共享设置。新版另加首屏艺术样式、内容密度和低资源视觉收敛。

访客通过外观面板选择的偏好会保存在自己的浏览器；后台改的是默认样式，不能保证覆盖已经有个人选择的访客。验收管理员默认效果时使用未设置偏好的浏览器或清除本站偏好。

强动画与透明表面不一定适合所有设备或内容。使用减少动态效果的系统偏好时，页面会减少非必要动效。深色与手机端分别检查文字对比度、按钮可见性和长标题，不要只看桌面首页。

## 3. 页面结构和导航

「布局」设置控制标准布局选项，「布局工作台」负责22个位置的组件编排，支持草稿、发布、最近20次历史及恢复。导航管理可调整内部/外部链接、顺序与显示人群；模块关闭会影响相应导航和服务入口，不应只隐藏菜单却保留写入接口。

工作台使用可验证的数据组件，不能上传原主题的 PHP 模板。模板、导入文件和跨站内容 ID 的操作见 NEW_MODULES.md。运营者需要保留自己的布局JSON备份；内置历史仅保留20次，不能替代完整备份。详见PLATFORM_017.md。

## 4. 内容、评论与资源

内容管理创建文章、帖子、页面或商品，设置分类、标签、摘要、封面、状态、展示时间和访问权限。公开摘要不应填写准备收费的正文；受限正文、私有附件需通过权限字段保护，不能只在前端 CSS 隐藏。

用户投稿按审核流程处理。评论和举报在审核页处理；可以配置评论展示人群、置顶回复等。用户可点赞、收藏、关注和发送私信，经营者应制定可接受内容规则并及时处理举报。

媒体上传后应检查类型与访问级别，普通资源不要从公开外链直接替代私有下载。超过主机空间、上传上限或 open_basedir 的问题需要面板调整。后台显示上传成功后，仍应分别用无权限与有权限账号验证下载。

## 5. 会员、任务和资产

会员套餐设置等级、期限、价格和启用；VIP 1–3 期限独立。资产、兑换码、签到和任务奖励使用统一账本。管理员调账必须填写可审计原因，不以手改 SQL 代替调账操作。

注册邀请码按次数和到期配置；生成的明文应即时安全保存。任务不能靠改页面上的数字达成，领取证明从真实评论/投稿/资料等取得。更多限制见 NEW_MODULES.md。

余额、积分、代币和推荐佣金并非同一种资产，用户转账与提现默认谨慎开启。推荐佣金不是作者出售文章的收入分成。提现在确认外部真实打款后才能后台标记，不能点一下就假装已经付到银行卡。

## 6. 商城与订单

数字资源、卡密和实物各有履约方式。规格/卡密从专门页面维护，不通过修改商品展示库存伪造可发卡数量。会员与活动价、优惠券范围在定价工作台和券管理维护；组合优惠按COMMERCE_016.md执行，不等于任意促销规则。

订单管理用于检查资产扣减、履约、发货、退款申请和审核。0.16起提供四种官方直连及单位订单全额原路退款适配，自动代付仅PayPal Payouts；真实服务和资金仍需联调，详见PAYMENTS.md。0.17的物流轨迹不会自动确认收货，账单导入不会操作资金。

## 7. 日常维护

定期核对商户账单、站内订单与流水，处理异常通知、退款、提现和内部佣金负债。定期备份数据库、原配置密钥与存储，并实际恢复到隔离环境。系统清理不能代替备份，也不应删除金融证据来省空间。

程序没有任意插件执行入口或自动热更新。从 0.9.0 升级看 UPGRADE.md；跨主机迁移需保留 secret、数据库和媒体的一致性，不要重新跑安装器生成新密钥覆盖旧站。

## 新增入口：动效、问答投票与邮箱

「动效工作台」(`/admin/index.php?tab=motion`)：预设、曲线、交错与位移、光点/透视/磁吸、首屏视差、日夜转场和持续装饰，实时预览后保存。预览不自动写入数据库。完整调校说明见 MOTION_GUIDE.md。

「问答与投票」(`/admin/index.php?tab=threads`)：查阅讨论类型并进入原内容编辑器。新帖类型普通讨论/问答/投票共用审核与内容权限；投票已有第一票后锁定问题、选项、截止和结果隐私。前台作者或后台内容编辑者可采纳回答，审核拒绝时自动撤销。详细见 EMAIL_COMMUNITY.md。

「设置 → 邮件」：配置 SMTP，确认实际送达后可开启注册必填邮箱验证。用户改邮箱在其资料页，需要当前密码和新邮箱证明；管理员人工改邮箱不会把它伪装为已验证。

「设置 → 模块」关闭问答/投票会同时关闭服务端对应入口，不删除历史数据。「设置 → 布局」控制阅读目录，目录仅从当前已授权正文生成。认证用户标记与邮箱已验证不是同一属性。

## 0.12 新入口

「圈子与成员」管理加入状态、人工期限与暂停；「积分悬赏」处理未结清积分；「商品评价」审核实际购买用户的文字评分。分类表单增加父级与读/写策略，商品交付类型增加邀请码，投票增加最多选择数量。先看 `COMMUNITY_COMMERCE.md` 的退款、期限与注册模式限制。

动效实验室新增物理弹簧响应、刚度/阻尼/质量与实时图；布局设置新增灯箱与原生分享。当前共有 192 项集中设置/13 组，36 项是实验室统一的动效参数。关闭新业务开关不会假装清除已有订单、资产或审计历史。

手机后台导航有焦点约束和 Escape 关闭；在桌面普通侧栏仍然常驻。灯箱与分享是浏览器增强，不改变后端访问权限。


## 0.13 作者与发现管理

在交易设置开启作者分成并配置比例/等待期；用户编辑批准作者并设置独立基点比例。作者收益列表位于 `/admin/index.php?tab=creators`，提现审核显示来源资产。后台内容编辑的作者定价许可用于控制旧内容能否由作者修改价格；默认不放开旧内容。

阅读记录全站开关在模块分组，条数限制在用户分组；个人在阅读历史页选择是否保存。后台不提供查看任意用户阅读历史的运营页。搜索联想可独立关闭；关闭增强不必关闭普通搜索。菜单管理可选择创作中心、阅读历史和关注动态。

新增状态与导航动效同时可以在外观设置和动效实验室管理，定义和保存均由同一个设置服务处理。具体路径和验收见 `CREATOR_AND_DISCOVERY.md`。

## 0.14 安全、定价与自检

前台“安全中心”绑定身份验证器、保存八个恢复码、退出其他登录。管理员也从个人账户入口操作，后台登录同样检查已绑定的第二因素；不是另做一套绕过验证的管理密码。用户设置的“允许新绑定”不等于强制全员启用，关闭它不会解除既有保护。

“定价工作台”维护内容/商品的三档会员付款比例和限时价格，数字越小越便宜，0 是免费。优惠券可设范围、指定内容、开始时间与最低等级；默认不叠加特别价。价格从统一服务算出，保存后的旧订单不重新计算。

“系统”底部运行部署自检或下载 JSON。自检是当前主机基础能力核查，报告中需要人工检查的项目必须继续验收，不能把 HTTPS 配置字符串等同证书已部署。

“布局”控制专注阅读；“动效实验室 → 状态与导航”新增布局重排开关，时间参数可保存 0ms。操作与恢复详见 `SECURITY_PRICING.md`。

## 0.16 新增操作入口

交易中心查看总支付与运行有界核付；运费/促销编辑版本化规则；售后/代付处理退换货、原路退款、PayPal Payouts、历史会员权益核对和升级回滚。媒体工作台提供本地分片和私有 S3；翻译编辑器管理中英草稿及审核；布局工作台新增全站/内容插槽及独立页面。

前后台共用中英偏好；新结算先复核再确认，访客通过随机私密凭据授权而非邮箱检索。操作与限制详见 COMMERCE_016.md、MEDIA_LANGUAGE_BUILDER.md；旧章节的功能缺漏描述属于此前版本，当前范围以 FEATURE_MATRIX.md 为准。

## 0.17 新工作台

“课程工作台”管理来源内容、章节、预览与私有资源，前台学习中心提供账户进度和笔记。“搜索索引”提供状态、继续构建及重建，不需要SSH。“物流履约”关联实物订单、手工轨迹及可选快递100。“账单核对”只生成标准CSV差异报告，不等同会计对账或自动改账。“客服工单”处理私有对话、可编辑回复模板和状态。

前后台语言偏好独立保存；课程标题等商家内容不自动翻译。各模块的权限、数量限制、工作流和验收步骤见PLATFORM_017.md、STATEMENT_FORMAT.md和ACCEPTANCE_017.md。


## 0.18.0 新增入口

后台“恢复保险库”用于创建、下载和删除本地加密副本。创建与导出涉及敏感数据，需管理员当前密码，已启用双因素时还需验证码。备份密码不是管理员密码，应用不会替你保存。保存到同一台主机不是异地备份，下载后要验证并移至安全位置。

后台“搜索索引”保留本地重建，新增远端队列统计、分批加入和单次/受限连续推进。先到站点设置配置搜索引擎、HTTPS 地址、专用索引、服务端密钥及公开元数据同意项；不要把异步受理当成同步完成。

后台“物流轨迹”按订单选择包裹；已有默认包裹可继续编辑，新增包裹独立拥有运单和事件。买家在物流页切换包裹，不必把两票快递的事件混成一条。

站点设置包含邮箱验证码多窗口配额、备份体积/保留数；设置范围有服务器端验证。操作顺序、错误处理和真实服务验收见 `PLATFORM_018.md`、`BACKUP_RECOVERY.md` 与 `ACCEPTANCE_018.md`。

0.20 新增：导航可选择“文章归档”，模块页可开启/关闭；系统页能力报告包含 PHP 上传、内存、执行时间和输入限制。评论排序和分页在前台使用。详见 PLATFORM_020.md。

0.20 补充：后台视觉素材库（79 图标、6 个独立生成二次元图标、7 个页面位置）、6 张独立封面、导航图标、简洁阅读样式；修复上传控件回填与预览；升级至结构 v12。使用方法见 PLATFORM_020.md。

## 0.21 文章与快讯

“内容与发布 → 快讯”管理短消息和发布时间；“站点配置 → 文章与版权”管理阅读组件、图片位置及版权模板，文章编辑器单独填写来源和版权类型。视觉素材库增加快讯信使图标，总计80个可配置符号。详细操作见 [PLATFORM_021.md](PLATFORM_021.md)。
