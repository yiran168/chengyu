## 浏览器发现的实际缺陷

1. 布局工作台将多项属性错误拼入一个属性名，通用表单函数将其过滤，脚本找不到 data-layout-document 后提前退出，导致“添加模块”无反应。修复为独立的属性键；HTTP检查实际HTML包含有效JSON注册表，浏览器验证添加/复制/排序/保存草稿/重新进入/删除/发布。
2. 添加条目按钮沿用30px图标按钮样式，中文标签被挤成竖排。为该共用按钮增加自适应宽度及合理内边距，验证文字不超出按钮并检查截图。
3. 菜单“查看全部”、FAQ问题标签及轮播/按钮组件标签存在翻译缺失或语境错误，已修正。
4. 0.23.4包内运行版本仍报告0.23.3，本版统一为0.24.0并增加元数据一致性回归。

菜单检查覆盖1100/1280/1440桌面边界、390手机、Enter/Escape/焦点、无JS路径及减少动态效果。FAQ页面覆盖320/390/768/1440宽度、原生展开、旧文本兼容与转义。8张新截图单独标记024；先前193张截图及完整200项浏览器结果仍属于0.23.0，未混入本轮通过数。

升级保留余额、原订单、付费访问、受保护正文、加密资源和全部原菜单字段；新菜单字段默认关闭，重复迁移不改变数据。旧包版本号错误已如实保留在升级证据中，未篡改为0.23.4。
