## PHP 7.4–8.5：同功能、同源码

本版使用 PHP 7.4 可表达的语法与运行时接口，延续 0.10.0 对旧支付版本门槛的移除。没有为旧 PHP 设计少功能版本。业务开关由站点设置和权限决定，不由 PHP 小版本决定；HTTPS、扩展和主机权限属于同样的运行条件。

## 生产必需能力

64 位 PHP；PDO 及与所选数据库对应的 `pdo_mysql` 或 `pdo_sqlite`；OpenSSL；Fileinfo；会话；随机数和密码哈希接口；可以写入专用存储。安装器检查基础能力，但无法改变主机扩展、磁盘配额或出站网络规则。

MySQL 分支使用 InnoDB、utf8mb4，面向 MySQL 5.7 及以上的语法范围；本环境**没有 MySQL 服务器或原生 PDO 驱动验收证据**。不能把这一设计范围当作 MariaDB 每个版本的兼容认证。数据库账户安装/升级需要建表、改表、索引权限，运行需要正常读写。

SQLite 生产分支使用原生 PDO，数据库必须在 Web 根目录之外；要求 SQLite 支持本程序使用的 WAL 和事务行为。免费主机无法访问外部私有目录时优先用 MySQL，而不是把 SQLite 放进公开目录再假设扩展名没人知道。

测试专用 `tests/Support/FfiSqlite.php` 不属于生产替代驱动，不应上传 `tests/`，也不要求免费主机打开 FFI。站点不要求安装 Composer、Node、Redis、队列守护、cron 或 SSH。开发测试工具与生产运行依赖分离。

## HTTPS 与外部服务

在线充值一律要求配置有效 HTTPS，并能从公网接收支付通知。没有按 PHP 版本区别放行不安全 HTTP 收款。SMTP 发信依赖出站网络、可验证的 TLS、正确服务商授权；这些不能由本包代替开通。

虚拟主机使用主机面板安装证书。VPS 附 Caddy 配置和新服务器辅助脚本，符合自动 HTTPS 条件时由 Caddy 处理；没有让 PHP 越权重载别人的 Web 服务。

## Web 服务和浏览器

Apache/LiteSpeed 需允许随包访问控制文件生效；Nginx 合并专门拒绝目录规则；IIS 配置模板未实机验证。根目录部署提供实体 `/admin`，无 WordPress 重写规则；子目录相应为 `/子目录/admin`。

前端面向支持 CSS 自定义属性和现代原生 JavaScript 的浏览器。毛玻璃能力不支持时使用普通表面；减少动态效果偏好会收敛动画，隐藏页面暂停部分背景动效。没有旧版 IE 全功能兼容保证。组件编排可在无 JS 时用经服务端校验的 JSON 入口，网站所有交互并不都具有完整无 JS 等价界面。

## 本轮新增模块的相同运行路径

`Verification`、`Threads`、`Motion`、`Categories`、`Bounties`、`Reviews`、`Creator`、`Discovery`、`Pricing`、`SecondFactor`、`Totp`、`Diagnostics` 的 PHP 层与现有业务使用相同数据库、密码/随机数、邮件和模板接口，没有按 PHP 小版本关闭模块。前端的 Document View Transitions、IntersectionObserver、Web Animations、玻璃和精细指针是浏览器能力，与 PHP 7.4 或 8.5 无关；不支持某项装饰时保留业务并采用静态/直接切换，不伪造受支持状态。

新代码避免 PHP 8 专用语法和新增运行时函数；这种源码检查只说明兼容目标，不替代每个版本实际执行。7.4/8.0/8.1 的上游安全维护状态与功能兼容是两件事；建议部署到仍获安全维护的版本，但程序不按小版本禁用功能。

## 0.14 的验证增强

后台“系统 → 部署自检”可在实际主机按需验证原生 PDO、扩展、加密、整数/中文绑定和数据库回滚，并导出 JSON。它不是七个运行时的全功能测试，也不是公网目录/TLS/支付证据。

CI 新增原生驱动前置断言：SQLite 任务缺 `pdo_sqlite` 或 MySQL 任务缺 `pdo_mysql` 会立即失败，不允许回退测试适配层后标为原生通过。CLI 恢复工具也加入各版本语法检查。14 组配置本轮未执行。

身份验证器使用 PHP 7.4 已有的 HMAC/随机数/整数/加密接口；价格使用整数与统一事务。没有按小版本关闭安全、定价、支付、作者收益或新视觉配置。旧运行时上游停止安全支持与应用同功能目标仍是两个问题。

## 0.15 外部连接条件

新 OAuth、主动查单、快照、永久会员和徽章共用现有 PHP 7.4 语法与接口。第三方连接需 `stream_socket_client`、OpenSSL、CA、公网 DNS/443，不依赖 cURL、`allow_url_fopen` 或守护进程。限制出站的主机不会被程序假装为连接成功；请开通主机条件后验收。

## 0.16 共同运行条件

新支付/退款/代付/会员/运费/促销/媒体/翻译服务不按 PHP 小版本关功能。出站 API 需要 HTTPS/443、DNS、可信 CA、stream_socket_client 和准确时钟；分片合并需文件锁及约三倍文件大小的空闲峰值空间；S3 需要私有桶、CORS 和条件复制权限。虚拟主机无人值守任务需外部可信调度，后台按钮始终可手动执行。

数据库迁移 v8，安装格式仍为 1。生产不使用 FFI，缺原生 PDO 应修复主机条件。源码的 PHP 7.4 兼容检查不代替七个版本真实执行，14 组 CI 配置本轮仍未运行。

## 0.17 共同运行条件

课程、索引搜索、布局版本、客服和标准账单核对复用原生PDO与PHP7.4语法范围，不要求新增守护进程。索引构建由每次HTTP请求处理10条，前台未构建完成时回退原检索。课程资源大小仍受现有媒体/主机限制。

快递100查询需要与支付相同的HTTPS出站能力和可用服务凭据，不要求cURL。数据库新增结构v9，安装配置格式仍为1。仅PHP8.4.23实际执行；原生数据库、其他PHP运行时与真实免费主机未被本轮测试结果覆盖。
