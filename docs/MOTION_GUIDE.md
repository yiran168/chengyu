# 动效、曲线与视觉工作台

适用 0.17.0（保留早期动效模块说明）。入口：后台导航「动效实验室」，或 `/admin/index.php?tab=motion`。只有具备设置权限的管理员能够保存。所有动效不参与权限、库存、付款或内容可见性的判断。

## 一、先选择基调，再微调

页面顶部有「安静专注」「自然流动」「光感表达」三套预设。点击只改变当前浏览器的预览和表单；**按下保存才写入数据库**。离开页面而不保存不会更改网站默认值；预览也不是另一套演示动画，而是调用网站相同的 `CYMotion` 引擎。

安静预设使用 280ms 和较小位移，关闭卡片透视、磁吸、持续装饰等；自然流动预设为 480ms，保留柔和入场、光点与轻透视；光感预设为 650ms，使用弹性曲线并启用更明显的层次。预设只覆盖它列出的相关项，玻璃、主题、纹理及其余配置继续保留，避免意外重置整组外观设置。

五套配色和玻璃仍在「外观」页面选择。玻璃档位为关闭、磨砂、棱镜、流体；名称是本项目视觉风格，不保证所有浏览器都有真实折射或相同合成效果。颜色模式是明亮、深色、跟随系统；允许访客自选时，本地选择可覆盖站点默认主题，不影响后端业务。

## 二、曲线到底控制什么

预置曲线由服务端 `Core/Motion.php` 唯一定义，并输出给前端与工作台读取，避免两处数值不一致。

| 曲线 | 参数 cubic-bezier(x1,y1,x2,y2) | 表现 |
| --- | --- | --- |
| gentle | 0.22,1,0.36,1 | 较快响应、柔和落定 |
| snappy | 0.2,0.8,0.2,1 | 轻快、直接 |
| elastic | 0.34,1.56,0.64,1 | 轻微超出终点再回落 |
| cinematic | 0.76,0,0.24,1 | 起落更明显的缓入缓出 |
| linear | 0,0,1,1 | 匀速 |
| custom | 自定义四个控制值 | 以工作台曲线图与实物预览确认 |

自定义值以百分数填写：X1/X2 为 0–100，Y1/Y2 为 -100–200。横轴是时间，纵轴是进度；Y 大于 100 可以产生超调。字段经后端白名单和数值范围校验，不接收任意 CSS。工作台 SVG 实时显示控制点、曲线与 CSS 参数，也可点击重播比较持续时间。

全局时间动画时长 0–1200ms；卡片悬浮位移 0–12px，显现位移 0–40px，交错间隔 0–120ms。同一批入场的累计延迟封顶 360ms，避免下方内容要等很久才显示。弹层关闭会采用更短的离场时间，按钮反馈也不刻意等待整个页面动画结束。

## 三、效果与开关

| 类别 | 可调内容 | 行为 |
| --- | --- | --- |
| 入场 | 上移、缩放、模糊显现；位移、交错、时长 | IntersectionObserver 检查进入视区，显现后不重复隐藏 |
| 光与深度 | 卡片跟随光点、透视、最大倾角 0–8 度、柔和扫光 | 面向鼠标/精细指针；触屏不强行模拟悬停 |
| 按钮 | 涟漪、磁吸、最大位移 0–12px | 保留正常点击、焦点和表单提交；不会修改业务状态 |
| 首屏 | 指针视差、背景光、粒子、纹理、持续装饰 | 离屏或标签页隐藏时暂停相应连续装饰 |
| 主题切换 | 淡入、圆形展开、滑动 | 支持 Document View Transitions 的浏览器增强；不支持则直接切换 |
| 弹层 | 入场/离场、Escape 关闭 | 基于原生 dialog 与 Web Animations；关闭后恢复原生焦点语义 |
| 阅读 | 阅读进度、文章目录 | 目录仅从页面已经授权输出的正文标题生成 |

「页面过渡」现在同时提供页面进入反馈与同源跨文档 View Transition 的条件开启。参与页面都需启用、浏览器需支持；不支持时按正常多页导航。已移除旧的 130ms 链接等待和 160ms 提交后跳转等待，点击不为装饰而人为延迟。它不是 SPA，也不缓存或伪造订单响应。本环境未完成真实浏览器 URL 导航验收，因此跨文档转场不能标为实机通过。

## 四、无障碍与性能优先级

系统 `prefers-reduced-motion: reduce` 优先于后台预设，装饰运动关闭，但购买、下载、表单、权限和全部模块保留。工作台此时仍可编辑保存数值，只是不强制播放预览动画。

低资源收敛使用浏览器可报告的节流/硬件提示，关闭部分昂贵玻璃与指针效果。不是服务器根据 PHP 版本减少功能，也不是能准确测量所有设备性能的基准测试。无法报告硬件信息时仍按常规配置运行。

弹簧模式由指针事件激活统一 requestAnimationFrame 调度；只有正在移动或回到静止的元素参与，收敛后自动停止，不留下空闲全局循环。隐藏页面、失焦或减少动态效果会清除待动元素。曲线模式保留原有渐变路径，视觉设置集中在 CSS 自定义属性。内容默认可见，仅在引擎初始化成功后标记等待显现；禁用 JavaScript 不会把正文永久藏起来。减少动态效果与页面隐藏也会取消或暂停相应动画。

## 五、排查

保存后效果没变化：确认提示成功，清浏览器/站点静态缓存；查看访客本地主题选择、系统减少动态效果、低资源模式、页面是否在后台，以及设备是否支持精细指针。旧浏览器直接主题切换是预期增强回退，不表示 PHP 缺失该模块。

感觉晃动：选安静预设，降低透视与悬浮，关闭粒子、持续装饰和磁吸；保留短时按钮反馈。光感预设并非适合所有内容站。

布局边缘空白：先用真实浏览器检查是否能横向滚动；某些全页截图会包含已经被根元素裁剪的离屏装饰，截图宽度不等于页面实际可滚动宽度。随包截图按真实视口宽度截取，布局测试另行检查 DOM 滚动宽度。

首次上线用键盘 Tab、Escape 和手机触摸验证导航、表单与弹层，再逐项启用昂贵效果。没有用截图保证“比某个产品更好看”；预设、参数与业务体验需要结合实际内容选择。

## 六、物理弹簧：保留速度，而不是重播一次 easing

选择「指针响应 → 弹簧」，调节刚度 40–480、阻尼 8–60、质量 0.40–2.50（表单按百分之一填写 40–250）。自然流动预设为 180/24/1.00；光感表达为 160/17/1.10；安静预设使用曲线路径。

`spring.js` 解析求解欠阻尼、临界阻尼、过阻尼三种状态。指针目标改变时携带上一次位置和速度，反向移动不会忽然把速度清零；相同真实时间下的结果不依赖简单“每帧乘固定百分比”的帧率近似。运动幅度有视觉限制，并非让卡片任意越界。

工作台显示阻尼比、响应曲线和采样收敛时间，点击重播时演示使用同一个求解器。刚度大通常跟手更快，阻尼低容易超调，质量增大会改变回落；先选择预设再微调。**全局毫秒时长控制入场/弹层等时间动画，不决定弹簧的自然收敛时间。**

卡片倾斜、悬浮与按钮磁吸共用求解器，正在物理更新的元素不会再叠加 CSS transform 过渡导致“双重拖延”。触屏不强造鼠标悬停；减少动态效果时显示静态可用界面。42 项算法测试验证三类阻尼、分步时间一致性、速度保留、非法输入与参数角点；它不等于所有设备上固定 60/120 帧性能保证。

## 七、折叠、导航与媒体

折叠面板使用原生 details 语义，增强模式动画高度可被下一次点击反向打断；完成后取消残留填充效果并清理内联高度，避免打开两次后内容被旧高度裁剪。禁用动效时直接开关，禁用 JavaScript 时仍可用原生控件。

移动后台导航支持遮罩关闭、Escape、Tab 焦点范围与关闭后恢复触发按钮焦点；打开时后台主内容 inert。桌面不显示只用于手机的菜单按钮。无 JavaScript 时保留可访问侧栏，不把管理导航永久隐藏。

「布局」中的图片灯箱只从页面已经授权输出的封面/正文图片构建，支持前后切换、计数、键盘、双倍缩放和失败状态；不会从未解锁正文偷偷提取图片。现有 Markdown 并不等价于全功能图库编辑器，主要可对封面及已经渲染的图片增强。部分原生能力缺失时保留原图阅读。

分享先尝试系统原生分享；不支持时尝试复制，复制也不可用时显示可选择的真实规范链接。用户取消系统分享不会被当成错误反复弹窗。没有加载第三方分享 SDK 或追踪脚本，没有生成海报/二维码的完整功能。

资料参考：MDN View Transition API，https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API （2026-09-06 核查）。不同浏览器的能力与授权规则需要在实际站点验收。


## 0.13：状态与导航微交互

「动效实验室 → 状态与导航」新增三个独立开关：`motion_navigation`（导航指示线）、`motion_feedback`（表单/通知反馈）、`motion_images`（已加载图片显现）。它们仍服从总动效开关、减少动态效果和低资源模式；所有新动画使用 `CYMotion.animate` 及统一曲线/时长，不维护另一套私有曲线。

导航指示线根据当前条目、指针和键盘焦点测量位置。用户快速反向切换时从当前可见位置续接，不先闪回原点；关闭该装饰不影响实际链接。动效实验室内有三个状态按钮与通知预览，可立即操作，不需要保存到正式站点。

表单提交立即防重并设置 `aria-busy`，真正请求超过 180ms 才出现装饰旋转指示，短请求不闪一下。按钮在失败/完成后恢复原来的禁用状态；失败同时提供文字提示，不能仅靠颜色或摇晃。保存和跳转不等待动画播放完毕。

通知最多同时 4 条，有明确关闭按钮，文字按文本处理而非 HTML。成功提示约 5 秒、错误约 9 秒后关闭，鼠标停留或键盘焦点进入时暂停；键盘关闭后尽力恢复触发元素焦点。减少动态效果时通知仍可用，仅不播放进出移动。

搜索结果到达采用轻微显现；图片只在成功加载后装饰，不把 opacity=0 当正文前置条件。失败图片、无 JS、旧浏览器或动画被关闭，不应造成权限已授予内容永久看不见。

这几项是原生 DOM/WAAPI 渐进增强，不依赖动画框架。后端业务不因不同 PHP 小版本而减少功能；动画支持与具体浏览器能力有关。实际导航转场尚未在当前环境完成真实浏览器 URL 验收，离线截图不证明跨文档转场已通过。

## 0.14：连续布局、专注阅读与报价反馈

新增 `motion_layout`，当前实验室统一管理 36 项参数。布局工作台按组件稳定编号记录正在显示的位置，更新 JSON/DOM 后只做位置变换；再次操作时从当前视觉位置重新测量，避免先跳回旧终点。动画完成、被取消、页面隐藏或减少动态效果时清理，不留 transform 或无意义常驻循环。

排序保留展开状态和编辑焦点，Alt+上/下键与原来的拖动/按钮并存。屏幕阅读器会听到位置变更；动画关闭后结构修改仍即时完成。它不依赖 PHP 小版本或安装动画框架。

修复折叠面板把 0ms 当空值并回退到 280ms 的错误。现在后台允许保存 0–1200ms，0ms 下入场直接可见、不保留交错等待。物理弹簧和连续背景有独立参数/开关；希望全部静止时关闭动效总开关或启用系统减少动态效果。

`reading_focus` 在布局设置控制专注阅读按钮：隐藏侧栏、优化文本宽度，保留正文和购买控件；不做缩放文字的重排动画，只在合适时给轻微透明度反馈。无脚本则保持正常布局。

报价由服务端生成，再按实际请求状态更新。新请求会取消旧请求，迟到响应不能替换最新金额；失败留下文字反馈并清除忙碌状态。刷新价格不收费，提交不等待动画，安全文本插入不接受接口返回 HTML。
