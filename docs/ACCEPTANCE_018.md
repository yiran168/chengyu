# 0.19 上线前实机验收

本地测试报告不能替代本页。先用不涉及真实资金的隔离站点操作，保留故障记录与恢复副本。

## 安装、保护与版本

确认64位PHP、原生PDO驱动、OpenSSL、Session及可写存储。程序版本0.23.3、数据库v15、配置格式1。旧站必须保留原 `secret`。不要为绕过错误删除 `app/`、`storage/` 等保护规则；访问配置、日志、备份和媒体封装路径时不应输出私密数据。后台仅管理员/对应角色可访问，上传包不能含私有安装口令或测试文件。

## 共用功能回归

验证旧账户和TOTP、钱包账目、会员永久权益和补差、付费正文/附件、访客通行证、购物车计价、原库存/卡密、物流、退款审批、作者收益冻结及导航权限。双语分别设置并刷新前后台；不得把日志或私密付费内容发送给搜索或翻译服务。

## 真实支付与服务

分别使用你实际签约的支付宝/微信/Stripe/PayPal产品，在其允许的测试或小额验收环境确认创建、通知验签、主动查单、拒绝假金额、重复通知、超时未知状态、原路退款和代付状态。不把mock协议测试当商户联调。实际账户不支持的支付产品线不要强行启用。

外部调度要验证认证、网络可达和执行记录；免费主机没有可靠调度时，只能人工推进，不能承诺无人值守及时完成。出站DNS/443、服务证书、存储CORS/对象访问、物流查询和翻译提供商应分别检测。

本轮已有七个PHP版本与原生PDO/MySQL证据，见 TEST_REPORT.md；两家免费主机、VPS新机脚本与公网服务仍未实测，完整浏览器套件仍待完成。高版本数据库回滚必须同步恢复代码和数据库，不可只换旧文件。

## 本版补充验收

确认新站独立口令生成后才允许安装，旧站升级不重装。检查多版本资源的购买/退款/停用权限、网盘提取码与失效反馈；配置轮播手机图片，验证焦点/隐藏页/减少动画暂停，以及无 JavaScript 横向滚动和按钮组真实链接。
