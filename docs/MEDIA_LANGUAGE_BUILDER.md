# 中英文、内容翻译、页面编排与媒体

## 一、中英文切换

前台顶栏和后台侧栏都有 EN／中文按钮，通过带 CSRF 的 POST 保存偏好；刷新后保留，会话及作用域明确的 `cy_locale_site` / `cy_locale_admin` cookie 不提供模板路径输入。后台“国际化”可以设置默认语言、是否协商浏览器语言及是否展示切换入口。0.17起前台、后台分别保存偏好；旧统一偏好仅作兼容回退。

界面使用统一语言入口 `Locale` 和 `app/lang/zh-CN.json`。英文为代码键值，中文为语言包。商家自定义的品牌、导航、商品名称、条款、正文不会被擅自自动翻译；语义不同但中文相同的短标签可能共享反向映射，发布前仍应校对自己常用页面。

## 二、内容翻译与隐私

后台“内容译文”选择内容与目标语言，可保存草稿或发布。译文只覆盖公开标题、摘要和正文；受保护正文保持原版，不向翻译服务发送。译文绑定原文编辑版本，原文一旦变更，旧译文不再展示或参与检索，需校对后重新发布。

可选 LibreTranslate HTTPS `/translate` 兼容服务。填写完整 API 地址和可选密钥，勾选发送公开文本的确认后生成草稿。默认没有第三方地址，不会自动把全站文章上传。服务商可能收费或有配额；请自己确认数据处理条款。自动翻译不处理过长字段，不保证代码、专有词、法律或交易文案准确；人工审核后再发布。

搜索采用公开元数据与有效译文。0.17新增可分批构建的便携倒排索引，支持英文词与CJK相邻字符组合、多词AND与相关性排序；未完成构建时回退legacy元数据查询。不会检索付费正文或绕过栏目限制，仍不是Meilisearch/OpenSearch。详见PLATFORM_017.md。

## 三、全站编排

后台“布局工作台”可选 22 个插槽：home、articles、forum、shop；global_before／global_after；article_before／article_after；page_before／page_after；page1–page12。独立页面地址为：

```text
/index.php?r=landing&slot=page1
```

11 种区块：标题、文字、内容、专题、行动按钮、统计、链接、留白、首屏、问答、媒体。支持排序、复制、导入／导出、设备与外观配置；访客／会员／VIP 条件在服务器决定，不是仅用 CSS 隐藏机密内容。

问答区块每行写“问题|答案”，最多 20 条。媒体区块使用已存在的媒体 ID，遵守媒体访问权限。按钮选择落地页时配置对应 pageN。给区块取稳定且唯一的 ID；系统也给 DOM 标识加插槽前缀，避免全局和页面内同名冲突。

0.17新增独立草稿、发布、放弃和最近20次发布历史；恢复会创建新版本并检测并发冲突。它仍是安全结构化编排，不提供任意PHP/JS注入或无限自由画布。用户上传的商业主题模板不能直接导入。已存在独立内容“页面”的正文与 page1–page12 编排页是不同入口。

## 四、本地分片上传

后台“媒体工作台”选择本地续传模式，选择文件并开始。每片为 256 KiB，逐片校验，最后按原顺序拼装并执行统一 MIME／尺寸校验；缺片不能发布，相同片重复发送不增加媒体记录。可暂停、选回同一个文件并继续，浏览器仅记住任务标识和文件指纹，不保存文件正文或存储密钥。

默认最大文件 256 MiB、未完成总配额 512 MiB，每个管理账户最多 8 个未完成任务；可以调小。不是主机保证容量。为拼装和正式文件需保留约三倍文件大小再加余量，且单次完成阶段仍受 PHP 执行时间限制。免费 1 GB 空间不适合存放多个大视频；优先小文件验收或使用对象存储。

仅管理权限可使用工作台，普通用户仍走原来的受限上传。允许的资源类型包括图片、文本、PDF、ZIP、MP4、MP3；SVG／可执行脚本不作为可公开执行文件接受。临时片和本地正式文件都用受保护封装，仍需保持目录拒绝访问规则。

未完成任务到期后要在工作台取消，释放配额和临时片；没有声称已实现自动清理守护服务。大文件续传不等于视频转码、直播、HLS 或 DRM。

## 五、S3／R2 私有对象存储

后台设置完整 HTTPS 桶端点、桶名、区域、访问密钥、私钥、前缀和可选会话令牌。两种端点形式：桶域名形式，或者服务域名后加 `/桶名`。AWS 区域必须和桶一致；R2 通常使用其要求的区域值 `auto`，以账户配置和官方文档为准。

示例仅为形态，不是可用凭证：

```text
AWS: https://your-bucket.s3.your-region.amazonaws.com
R2:  https://your-account.r2.cloudflarestorage.com/your-bucket
prefix: chengyu
```

**必须把桶设为私有并关闭公开读取。** 预签名并不会把原本公开的桶变私有。授予应用所需前缀的读、写和 CopyObject 所需权限，避免根账户权限；密钥变更前做好旧文件访问迁移。配置快照保留在每条媒体记录里，改站点新密钥不会自动迁移所有旧记录。

浏览器先上传到 `prefix/staging/随机ID`，短期 PUT 签名绑定类型、长度及任务。服务端验证 HEAD、样本、类型与 ETag，再条件复制到不可由该 PUT 链接覆盖的 `prefix/media/随机ID`，最后登记正式媒体。即使暂存 PUT 链接被重用，也不能覆盖已发布的正式对象；复制响应丢失可查询正式对象后恢复，不重建媒体记录。

跨域规则须允许你的网站**准确来源**，允许 PUT／GET／HEAD 和签名要求的 `content-type`、`x-amz-meta-cy-id` 等请求头；按供应商规则处理预检，暴露 ETag 等必要响应头。不要为省事给所有不可信来源开放写入。站点 CSP 仅放行当前配置的存储来源，变更端点后要验证旧链接和播放器。

给 staging 前缀设置至少一天后的生命周期清理，别误删 media 正式前缀。对象上传完成后临时对象不会自动删除，未设置生命周期会额外占存储。本版对象直传是单次 PUT，不是 S3 multipart 断点续传；本地续传与对象直传是两条不同路径。

下载先经过本站权限校验，之后得到约 120 秒的短签名链接。有效期内该链接仍是持有者可访问的能力，不能阻止购买者转发或保存文件；退款不能收回已经下载的副本。不要把签名 URL 长期写进公开文章。没有宣称 DRM。

## 0.17 课程化组织

媒体可关联课程章节，按来源文章/数字商品的购买、VIP、有效期和下架状态重新判权。免费预览意味着章节资源可访问，不要误复用收费资源。个人笔记/进度明确点击保存；没有转码、直播、证书或防刷学时。流程见PLATFORM_017.md。
