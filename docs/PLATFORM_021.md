# 0.21 文章阅读与快讯

2026-09-13。数据库结构 v13；本版使用同一套 PHP 7.4–8.5 代码，不依赖 WordPress。新增内容以独立服务和共享模板实现，旧站内容、账号、订单与素材不会被示例数据替换。

## 发布快讯

后台“内容与发布 → 快讯”可以新建、编辑、搜索和按状态筛选短消息。填写标题、正文、来源、可选图片和发布时间，选择草稿、已发布或归档。管理员与编辑可操作；普通会员没有发布权限。

标题最多 160 字符、正文最多 4000 字符，以纯文字显示，保留换行。图片通过原有上传控件选择公开媒体。来源仅接受 HTTP/HTTPS 链接。未来时间的已发布记录到时才对访客可见，按每次请求的站点时间判断，无需 SSH、队列或计划任务。服务器时钟和站点时区应正确。

前台入口为 `index.php?r=bulletins`，按日期分组、每页 20 条，支持月份筛选、关键字搜索和原生翻页。详情使用独立链接，可以复制分享；RSS 为 `feed.php?kind=bulletins`。站点地图自动列入当前公开快讯，草稿、归档与尚未到时的内容均不输出。

后台“模块”可关闭快讯；“布局”可关闭侧栏快讯。导航编辑器可以添加快讯入口并选用新图标。未添加导航时仍有页脚入口。关闭模块后访客页面与订阅关闭，后台保留管理入口。

重复的新建请求不会生成多条记录；同一请求标识改用另一份内容会被拒绝。已有快讯使用修订号，两个窗口同时修改时要求过期窗口刷新。没有批量抓取新闻、自动转载或外部新闻推送接口。

## 文章排版与版权

后台“站点配置 → 文章与版权”提供摘要、已选封面、作者卡片、上一篇/下一篇、相关阅读开关。文章列表默认采用图文列表，可选择网格或杂志排版；图片位置可选左侧、右侧或纯文字。访客自己选择的列表视图继续保留。商品展示不受“文章封面”开关影响。

文章编辑器的“来源与版权”可填写来源名称与原文地址，再选择默认、原创、授权发布、转载或不显示说明。站点版权模板可以自定义，支持 `{author}`、`{title}`、`{site}`、`{url}`。模板以纯文字输出，不执行 HTML、JavaScript 或 PHP。选择版权类型只是描述作品权利，不能代替原作者许可。

作者卡链接到已有用户主页。上下篇按创建时间和 ID 在同分类中定位；相关阅读为同分类最多四篇，按现有热度排序。这些查询复用内容列表的权限与发布时间过滤，不从私密正文提取推荐内容，也不把草稿标题暴露给访客。它不是语义推荐系统。

## 图标与动效

新生成的“快讯信使”是一只拿着珊瑚色报纸的小鸟，透明背景、192×192 WebP。与既有六个二次元图标分别设计。后台“视觉素材库”现有 80 个逻辑图标，其中 7 个是独立生成位图，其余为本项目代码矢量图标。可替换内置图标或自己的公开图片，并恢复默认。站标继续在外观设置管理，避免同一位置出现两个配置入口。

本轮阅读页优先保证文字宽度、行距、标题层级、清楚的来源和时间；快讯用日期分组和细分隔线。悬停只做小幅颜色或位置变化，触屏无需悬停即可操作；系统“减少动态效果”下正常阅读。原有动效实验室、曲线与主题设置仍可使用，没有为每条文章叠加循环闪光。

## 数据与部署

新增 `cy_bulletins`，内容表新增 `source_name`、`source_url`、`copyright_mode`。迁移可重复检查，新表纳入加密快照白名单。配置字段共 290 项、20 组；区块仍为 22 种、22 个位置。
