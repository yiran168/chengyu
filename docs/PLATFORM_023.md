# 0.23 图片选择与复用

后台「视觉素材库」、站点外观、导航图片、文章封面、正文插图和四张画廊图片现在共用「选择已有图片」按钮。用户头像等公开图片字段也使用相同入口。

1. 打开要编辑的位置，点击「选择已有图片」。
2. 输入原文件名的部分内容，点击搜索；默认显示「我上传的」。管理员和编辑还可选择「全部公开图片」。
3. 点击图片，核对预览、名称、附件编号、格式和大小，再点「使用这张图片」。
4. 回到原表单后点击保存，修改才生效。取消弹窗保留原值；「清除图片」只清除当前字段，不删除原文件。

内置二次元素材仍从原下拉框选择；图片库选择的是站内上传记录。修改一个字段不会覆盖另一个字段。视觉素材库选图会清空冲突的内置素材来源，并立即更新预览。

## 容量和权限

复用只回填已有附件编号，不复制文件、不占用第二份上传空间。图片列表每页12项，以编号游标翻页；输入百分号、下划线作为文件名文字搜索。只列出公开 PNG/JPEG/WebP/GIF，私有资源、文档、SVG和其他用户的私密媒体不出现在列表中。普通成员只可选择自己上传的图片。

确认时重新查询媒体及当前账号状态；图片已变成私有、类型不再受支持或权限已撤销时拒绝回填。真正保存表单时仍执行目标功能原有的图片校验。关闭窗口会取消仍在进行的查询，失败后可再次搜索；对同一图片重复选择不会新增记录。

每张不超过256 KiB的图片可以加载缩略显示，超过时显示占位，仅在用户点击后读取原图预览；不会一次读取12张大原图。此版本没有制作压缩缩略文件，不依赖GD/ImageMagick。透明底图可用PNG/WebP。媒体本体仍走原有存储与授权逻辑。

## 窗口与操作

桌面图片库使用940像素上限的图片网格与预览栏；手机改为单列。支持Esc、焦点返回、原有统一弹窗动效与减少动态效果。低高度桌面下视觉素材编辑栏正常随页面滚动，避免固定栏挡住下面的操作。

JavaScript关闭时选图按钮不显示，保留编号字段、文件上传和原生表单。新站不会自动产生示例媒体；图片为空时可先在当前字段上传，再使用图片库复用。

## 升级

0.22的结构v14升级至v15，为媒体公开范围/归属查询增加两个索引，不搬移文件，不改余额、购买权益和旧图片绑定。按[升级说明](UPGRADE.md)保留配置、数据库和storage，清理代码缓存后再使用。免费主机依然需要原生PDO、OpenSSL、fileinfo等已有运行条件，实际账号验收见[部署验收](ACCEPTANCE_018.md)。
