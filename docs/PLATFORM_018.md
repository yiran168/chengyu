# 0.18 搜索、包裹与安全工作台

本章仅说明本轮增量。旧课程、工单、账单与布局版本仍参见 `PLATFORM_017.md`；支付与售后参见 `COMMERCE_016.md`。

## 外置 Meilisearch

后台“设置 / 发现”选择 `meilisearch`，填写公开可达的HTTPS接口、专用 `cy_` 前缀索引和服务端API密钥，确认同意发送公开元数据和用户搜索词。服务必须在另一个可运行搜索进程的服务器或托管服务上；免费共享主机只运行PHP连接器，不需要在主机安装Docker。服务成本、数据处理与访问配额由你与提供商决定。

接口只接受HTTPS、443端口和公共IP解析，不能填localhost、私网、带用户名密码或查询参数的地址。VPS上的同机服务也需经受保护的HTTPS入口接入；不能关闭校验去访问内网。API密钥只留在服务端，给该专用索引配置搜索、文档写入/删除和任务读取所需的最小权限，不使用公开主密钥。

在“搜索工作台”先点击“加入下一批25篇”，逐批建立同步队列。然后“处理一个到期任务”，或启动一次最多12次请求的短同步会话。关闭或隐藏页面会停止继续发请求；队列在数据库保留。请求受理后不标记完成，之后必须取得远端任务成功状态；失败保留并退避重试。长时间无人管理需配置真实调度，并开启 `meili_jobs`；没有调度就不能保证及时同步。

同一文档变化会合并到同一队列项，并记录版本。只同步可匿名列出的已发布内容：标题、摘要、标签、当前有效中英译文标题与摘要。正文、付费正文、私信、账户、订单、笔记和工单不发送。归档、下架或权限变化会排队删除。

搜索最多取得200个远端候选，返回本站重新核对ID、内容版本、当前权限、栏目和发布时间，再与本地命中合并；本地结果总量决定分页，不直接信任远端总数。远端故障自动使用本地检索。仍支持用户获准访问的受限栏目本地匹配。

这不是所有子比智能筛选的等价实现：没有本站同义词/纠错管理界面、全文正文导出、分类聚合计数、OpenSearch/Elasticsearch或语义向量服务。远端同义词等参数须在专用搜索服务管理。切换供应商或禁用同步不会自动清空旧供应商的数据，必须单独删除旧索引。

服务端遵循官方POST搜索、全量文档替换和异步任务查询协议，见 `HOSTS_AND_SOURCES.md`。本轮采用协议桩测试，没有真实Meilisearch实例联网联调或大型索引压测。

## 一个订单多个包裹

在后台物流工作台填写已支付实物订单ID，添加第一包裹。之后可“添加另一个包裹”，设置标签、承运商代码与单号。每个包裹有单独轨迹、版本和查询时间；订单最多20个包裹。同一订单重复承运商/单号会被拒绝。相同新建请求重试不会重复建包裹。

切换顶部包裹卡可查看或修改指定包裹。变更运单只清除该包裹旧轨迹，不影响其他包裹。人工更新需含时区的时间、文字说明；远端快递100查询保留原签约、显式同意、间隔和单号匹配检查。

用户从订单进入物流，仅可查看自己的订单。不要以某一包裹的“已签收”自动推断整个订单完成；用户应收到所有包裹后才确认收货。物流变化不自动改余额、退款或结算。

这是多运单与轨迹管理，不包含每箱商品数量分配、跨SKU换货、多仓库存、电子面单、退件独立轨迹或承运商自动订阅。

## 邮箱验证码防滥发

后台安全设置可分别限制同IP/同收件人的10分钟、小时、天发送数，并设置收件人实际冷却秒数。邮箱经统一标准化后计数。七个限制在同一事务中判定，拒绝请求不额外消耗其他未超限额度。

六个次数时窗采用固定窗口，冷却时间连续计算，所以不能简单通过跨分钟边界绕过最小发送间隔。站点所有相关验证码用途共享收件人额度。它不等于新增阿里云/腾讯云短信、图形拼图验证或所有消息发送的反垃圾保护。被限流时等待窗口到期；不要在生产数据库清空限流表绕过保护。

## 界面与动画

恢复副本、搜索同步和多包裹页共享既有主题、色彩和曲线。包裹卡使用短距离悬停、选中标记和键盘焦点；恢复工作台有分层徽记。指针柔光仅在精细指针、启用动效且页面可见时运行，每个表面最多一个待执行动画帧，没有空闲无限循环。

关闭动效或系统选择减少动态效果后，新增位移和柔光停止。主要操作使用原生POST表单，JavaScript只增强体验；不是没有JavaScript就不能操作。后台与前台语言偏好仍分别保存。
