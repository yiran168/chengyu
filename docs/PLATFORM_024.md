# 0.24：内容导航与常见问题编辑

本版在原有后台基础上补充分类内容导航、逐条编辑的常见问题，并修复布局工作台无法添加组件的问题。数据库升级到 v16；无需 WordPress、Fileinfo 或图像处理扩展。

## 给导航展示最近文章或资源

进入「视觉与运营 → 导航菜单」，新建或编辑菜单：

1. 目标选「文章」「社区」或「商城」。分类可选对应类型的一个分类；不选则使用该类型的全部公开栏目。
2. 内容预览数量选 1–6，排序选最新发布、最多浏览或最近更新。选 0 只显示普通链接。
3. 选择图标、说明、上级和顺序，保存后在前台查看。分类链接与内容预览共用该菜单的访问条件。

全站最多开启 8 个内容菜单。它们读取已经发布且时间已到的真实内容；关闭模块、撤销分类权限或删除内容后，下一次请求即按新状态显示。公开分类中付费/VIP文章可以显示标题与封面，正文和下载地址不进入预览；受限分类会连同菜单分支一起隐藏。

桌面使用紧凑图文下拉，手机使用同一棵菜单树。按 Enter 展开，Escape 关闭并返回焦点；禁用 JavaScript 时仍可使用原生折叠导航。没有封面的条目使用文字排版。最多 8 次有界内容查询，相同配置在一次请求内复用结果，没有跨用户缓存菜单 HTML。

## 逐条编辑常见问题

打开「布局工作台」，选择页面，添加「常见问题」。每条独立填写问题和答案，可排序、删除；答案支持换行、Markdown 和普通竖线字符。每组件最多 12 条新问题，每个问题 120 字符、答案 2000 字符。

旧版 `问题|答案` 文本继续显示在新条目前，不会自动拆改或删除。编辑旧组件时会保留旧格式输入框。页面用原生折叠列表，不加载额外组件库。保存草稿不影响公开页面，发布后才生效；保留既有修订冲突检查和发布历史。

本轮浏览器检查发现并修复：工作台 JSON 输入框未正确输出 data 属性，导致编辑脚本提前退出；“添加条目”按钮沿用图标按钮的固定宽度，导致中文文字竖排溢出。FAQ、图集、轮播等条目编辑共用修正后的入口和按钮样式。

## 图标和页头

新增分别生成的「阅读手记」书本图标和「帮助与售后」耳机图标，逻辑名称为 `anime-reading`、`anime-support`。全站共有 83 个符号，其中 10 个独立生成的二次元图标。进入「视觉素材库」即可绑定自己的公开图片、换图或恢复默认，也可从菜单选择它们。

「站点设置 → 页头副标题」留空即隐藏，取代之前固定显示的英文口号。主标题、站标和既有视觉素材绑定保留。动效沿用站点统一曲线、减少动态效果偏好和键盘焦点，避免为了展示动效影响阅读。

## 升级与验证

按 [升级说明](UPGRADE.md) 备份后覆盖 app 和 assets。v16 只给导航加 3 个字段，旧菜单默认不开启内容预览。PHP 7.4–8.5 本地原生 SQLite、真实 HTTP、浏览器和旧库升级的结果见 [测试报告](TEST_REPORT.md)。萌哒云和蓝队云实际账号、最新 MySQL CI 与 VPS 装机未在本轮完成验证，不能把本地通过等同于全部套餐实测。
