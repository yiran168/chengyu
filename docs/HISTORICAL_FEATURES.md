# ICU7.8、官方早期档案至V9.1功能核对

核查日期2026-09-07。目标是发现功能缺口，而不是照抄主题实现、发布宣传或WordPress接口。状态“已有”仅指本工程存在对应模块，不表示完整等价或真实商户验收。

## 本轮实际来源

重新连续读取用户ICU三个RAR分卷，遍历13,652个归档条目，对主题目录952个文本文件建立路径/大小/摘要索引。主题头Version7.8；8个目标文件有符号/行号及定向控制流程核查记录，并未逐行审计所有952个文件。细节见 `REFERENCE_AUDIT.md`。

官网早期档案[A]自述V1.0–V5.9，当前可见独立条目主要为V2.0–V5.7，不声称取得全部V1.x和每个缺失小版本的正文。后续日志[B]核对V6–V9版本族和可见功能条目，最新V9.1为2026-09-01。直接抓取官网个别页面超时，采用官方域名搜索缓存补充；缓存可见内容与安装运行每个版本不是同一件事。

## 本轮核对后的开发取舍

发现既有导航已支持公开、登录、VIP与认证条件，因此没有重复建一套菜单。新搜索复用内容修订和权限入口，不把私密正文交给外部服务；包裹依附现有交易；验证码共用一套原子限流；备份读取固定业务表并用同一验证器进行检查和恢复。没有增加空驱动、假对账或假退款按钮。

仍未完成全部社交与短信、全部支付产品线/企业付款、部分退款与跨SKU售后、全小工具/任意画布、原始账单自动拉取与会计勾兑、原生OSS/COS、直播/转码/HLS/DRM、自动异地备份及WordPress迁移。详情以 `FEATURE_MATRIX.md` 为准。
