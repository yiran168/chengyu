# 账户安全、会员定价与部署自检（0.14 基础，0.15 更新）

本章对应可实际操作的前后台模块。业务实现独立，不依赖 WordPress、短信平台、第三方二维码网站、任务队列或新增常驻进程。

## 一、账户安全中心

前台登录后进入“我的 → 安全中心”，实际路由为 `/index.php?r=security`。后台用户也使用相同账户与登录验证；可以从后台进入前台个人中心操作。全站设置在“用户”分组控制是否允许**新绑定**。

### 绑定时间型身份验证器

输入当前密码后开始绑定。页面显示密钥，在自己的身份验证器中选择“手动输入密钥/时间型”：**SHA1、6 位、30 秒**。本项目不生成远程二维码，也不会把密钥发给二维码网站。不要把密钥、截图或生成的验证码发送给客服或其他人。

待绑定流程 10 分钟过期，且绑定当前账户、会话版本。再次输入当前密码与验证器中的当前验证码完成启用。成功后会撤销其他会话，本浏览器继续登录，并显示 **8 个恢复码**。

恢复码只展示一次、每个只能使用一次；先保存在与密码分离的离线安全位置再离开。数据库中保存其带站点密钥的摘要，不保存可直接使用的明文；身份验证器密钥使用站点加密服务保存为密文。

### 登录与防重放

已绑定用户在正常登录表单填写密码，并在“身份验证器或恢复码”栏提供证明。没有绑定的账户仍按原密码流程登录。

采用当前时间步前后各一个窗口容忍时钟偏差。绑定时刚用过的码已经被消费，立即再做受保护操作时要等待下一个时间步，或者使用尚未消费的恢复码。已接受的时间步不能再次使用；恢复码在同一账户事务锁下只消费一次，外层事务失败会恢复消费状态。

服务器和验证器时钟需同步。不要为方便而把验证窗口无限扩大。恢复码无自动到期日，但可以轮换、解除绑定或在恢复后重新绑定；被泄露时立即处置。

### 管理与恢复

“替换恢复码”要求当前密码与当前第二因素，生成八个新码，旧码全部立即失效；“解除绑定”也要求两项验证。“退出其他登录”在已绑定时同样要求第二因素，撤销其他会话但保留当前浏览器。

**邮箱找回密码不会移除身份验证器；关闭全站新绑定入口也不会跳过已启用的保护。** 没有设置一个可从 HTTP 调用的管理员万能解除接口。

手机丢失但有恢复码：用恢复码登录，在安全中心使用另一枚恢复码完成解绑或轮换，再绑定新设备。两个操作不能重复使用同一个码。

手机与恢复码都丢失：站点所有者可在有本地命令权限的环境，备份后使用完整包中、Web 根目录之外的工具：

```bash
php tools/recover-authenticator.php /absolute/path/to/site USER_ID CONFIRM-REVOKE-ALL-SESSIONS
```

该命令读取已安装站点配置，移除指定用户的身份验证器、递增会话版本并写审计；不修改密码。必须由有文件/数据库管理权限的站点所有者执行，不能把此工具复制到网站公开目录。免费主机没有命令权限时，应事前妥善保存恢复码；丢失后向可信主机管理员申请本地恢复，不提供绕过面板权限的 Web 后门。

本版没有强制全员绑定、硬件通行密钥、WebAuthn、登录设备地理识别或短信；0.15 新增三家第三方登录，见 CONNECTIONS_AND_OPERATIONS.md。TOTP 不是防钓鱼硬件凭据；不要据此承诺账户绝不会失窃。安全中心显示最近 20 条本人 `account.*` 审计，而不是任意用户的登录设备清单。

标准与算法测试参考：RFC 6238，https://www.rfc-editor.org/rfc/rfc6238.html 。本轮验证 SHA1 标准向量、窗口、重放、恢复码并发以及实际 HTTP 登录流程，没有宣称所有外部身份验证器产品均完成实机联调。

## 二、定价工作台

后台进入“定价工作台”，路由 `/admin/index.php?tab=pricing`。只有管理权限可以修改；普通作者没有因此获得改站点促销规则的权限。

左侧列出近期 300 条可选内容；较旧内容可直接填内容编号。右侧配置 VIP 1–3 的付款比例与限时活动。页面使用规则修订号，另一窗口先保存后，旧窗口提交会报冲突而不是静默覆盖。

### 金额与比例

商品基础价格和 SKU 价格仍在原内容/规格管理页面设置。这里的比例是**实际支付部分，以万分之一填写**：

| 填写 | 含义 | 基础金额 1000 分的结果 |
| --- | --- | --- |
| 10000 | 原价 | 1000 分 |
| 8000 | 付原价 80%，即八折 | 800 分 |
| 6000 | 付原价 60%，即六折 | 600 分 |
| 0 | 免费 | 0 |

低于最小资产单位的部分向下取整，所有运算使用整数。余额单位为分，积分/代币使用原有最小单位，不用浮点货币计算。

高等级继承较低等级中更优惠的比例。VIP 3 的配置若比 VIP 1 更贵，VIP 3 仍可使用 VIP 1 的低价；不是让高等级反而多付钱。会员资格仍由现有有效期限/开关决定。

会员价和限时活动价**择低，不连乘**。例如基础 100 元、会员付 80%、活动付 85%，该会员付 80 元，而不是 68 元。无会员访客看到当前活动 85 元，但仍需登录和满足权限才能购买。

活动价低于原价时必须填写合法开始、结束时间，结束晚于开始。日期按应用当前时区解释（本包默认 `Asia/Shanghai`）。区间为开始包含、结束不包含；请求时即时计算，不需要 cron，也不提前预约库存。下次请求自然恢复当时应有的价格。

关闭“会员与限时定价”或停用单条规则会恢复基础计价，不删除原规则，不重算旧订单。VIP 免费访问规则仍是内容权限的一部分，不能用报价接口绕过它。

### 优惠券

券新增可选范围：全部、内容、会员套餐；可指定单个内容编号、开始时间和最低会员等级。原有到期、全站次数、最低金额及每账户一次限制仍保留。券仅用于余额计价，不能对积分、代币或零价订单硬套金额券。

默认不允许券叠加已经生效的会员价或限时价。开启“优惠券叠加”后，**单张券**在当前特别价格上扣减；不是多张券相叠、满赠或跨店活动。

券额度锁定和次数增加发生在真正购买事务中。报价接口不消耗券；购买金额超上限、余额不足或其他后续步骤失败，预留次数随事务回滚。已用券的历史使用记录不会因退款自动变成“从未使用”。

### 页面报价与成交快照

单件购买页面先由服务端输出实际价格，JavaScript 不是显示金额的唯一来源。选择规格或输入优惠券后可点“核对优惠”；异步请求取消、防抖与序号校验防止旧响应覆盖新确认，返回文字以文本插入。

报价只供确认，不锁定价格、不预留库存、不扣款。提交仍由服务器重新计算。支持的单件购买表单携带最高确认金额：最终应付更高时返回 409 并不扣款，要求重新核对；金额更低时正常按更低值扣款。篡改这个上限不能强迫服务器用低价成交，只能造成拒绝。

**边界：**购物车页面汇总也用同一计价器，实际整车购买在事务中重新计价，0.15 已增加按三种资产分别校验的整车最高确认金额，超限整单回滚。禁用 JavaScript 的多规格表单仍可提交真实购买，却没有在切换选项时同步最高确认金额的增强逻辑；应核对选项与最终订单，不能把单件增强说成所有入口都锁价。购物车暂不提供优惠券输入。

新订单保存基础金额、会员等级、来源、比例、规则编号/修订号与券扣减快照。退款按原订单实际支付额退回站内资产，后续调价不改变旧单；作者收益与推荐佣金也沿用实际订单金额。没有把页面临时试算写成支付已成功。

本版不提供按会员等级填写固定绝对售价、升级补差/剩余天数折算、访客购买、阶梯量价、秒杀排队/库存预占、满赠/多券叠加、复杂运费或自动支付平台退款。

## 三、部署自检

后台“系统”中运行“部署自检”。通过有管理权限的 POST 和 CSRF 校验启动，也可下载 JSON；有频率限制并写审计，不对外提供公开 phpinfo。

自检实际执行：运行时及 64 位检查、PDO 是否原生、基础扩展、AES-GCM 加解密、密码哈希、中文/64 位整数参数绑定、临时行写入后回滚并验证不存在。MySQL 在有权限时额外检查应用表是否 InnoDB；检查存储是否可写、配置网址是否 HTTPS。

导出不包含商户密钥、数据库密码、用户资料或服务器绝对路径。报告仍含软件版本等运维信息，应只发给可信维护人员。`pass` 是该条本次检查成功，`warning` 是能力/证据不足，`manual` 需要真实部署人工验证。

自检**不会**主动向外部商户发钱、发邮件、申请证书或扫描公网目录；配置写着 HTTPS 不代表证书已有效。需要另查 `/app/`、`/storage/` 等敏感路径访问保护、TLS、上传执行限制、真实收款和邮件。测试适配器会明确显示非原生警告，不能拿它当 PDO/MySQL 认证。

这项基础自检不是对所有 PHP 小版本的全模块测试，也不会修复主机配额、扩展缺失或面板权限。生产不依赖测试 FFI，不要求为自检开通 shell、进程执行或网络下载能力。

## 四、专注阅读与布局重排

“布局”分组新增专注阅读按钮开关。启用后已授权文章/商品正文页可隐藏侧栏并调整阅读宽度，再次点击恢复；不改正文权限、不删除购买控件、不保存额外个人跟踪数据。无 JavaScript 时使用正常布局。

动效实验室新增“布局重排”开关。编辑器按稳定组件编号测量旧位置和新位置，只动画位置偏移；连续反向操作从正在显示的位置接上，结束后清理变换。展开状态、编辑焦点与实际 JSON 顺序一并保留。

可用原有拖动/上下按钮，也可在组件内按 Alt+上/下方向键。位置变更提供屏幕阅读器播报；关闭动画或系统减少动态效果时仍立即重排并保存正确顺序，不减业务功能。

全局时长允许 0–1200ms。0 表示这些时间动画立即完成，入场不保留交错等待；物理弹簧和持续装饰由各自开关及物理参数控制。要完全静止，请关闭动效总开关或使用系统减少动态效果，不把 0ms 与关闭所有连续装饰混为一谈。
