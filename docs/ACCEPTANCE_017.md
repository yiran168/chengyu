# 0.17 上线前人工验收清单

这是需要在你的真实测试站执行的清单，不是“本轮已经全部通过”的声明。先隔离副本，关闭真实商户和出站邮件，再测。生产涉及资金前另外验收外部渠道。

| 范围 | 操作 | 应看到 |
|---|---|---|
| 环境 | 后台系统自检 | 实际 PHP、原生 PDO 驱动、整数/中文绑定、事务回滚、加解密正常 |
| 目录保护 | 用无登录浏览器访问 app/config.php、storage/、备份路径 | 不可下载正文和目录列表；Apache/Nginx/IIS/Caddy规则按实际服务器生效 |
| 升级 | 0.16 副本覆盖程序后首次访问 | 数据库版本9，配置 secret 未变，旧卡密和对象配置仍可解密 |
| 旧业务 | 登录/TOTP、内容、SKU、卡密、钱包、会员、圈子 | 没有丢权限/余额/库存或重复交付 |
| 搜索 | 分批重建、关闭页面、恢复 | 游标延续；旧搜索在未完工时可用；正文、笔记、工单不可搜 |
| 课程 | 买前、买后、退款后、下架后访问 | 仅允许状态可读；免费预览边界清楚；私有附件同样撤权 |
| 学习记录 | 两个账号、两个窗口保存 | 账号隔离；旧版本保存被拒绝；笔记不公开 |
| 页面搭建 | 存草稿、发布、恢复、双窗口冲突 | 线上只在发布时改变；恢复生成新版本；不能静默覆盖 |
| 物流 | 别人的订单、改运单、陈旧结果、人工记录 | 权限拒绝；旧轨迹清理；不自动收货或退款 |
| 账单 | 重复文件、错币种、错金额、外部未知单 | 重复导入幂等；差异报告；余额/订单不变化 |
| 工单 | 本人/他人读取、重复回复、关闭再回复 | 数据隔离、重复抑制、先重开再回复 |
| 语言 | 前台中文、后台英文；清理旧Cookie再选 | 两处独立；商家自定义内容不被擅自改写 |
| 动效 | 320/390/768/1440宽、键盘、减少动态效果 | 页面无横向溢出，焦点可见，业务不依赖装饰动画 |
| 支付 | 自己签约渠道下单→通知→查单→退款 | 金额/币种/订单核对；重复通知一次入账；回跳参数不能伪造成功 |
| 自动任务 | 一次任务、重复nonce、断网恢复 | 受认证、限量执行；重放拒绝；无调度就不宣称自动推进 |
| 外部服务 | 快递100/S3/翻译/SMTP的真实账号 | TLS、主机DNS/出站、额度、权限和异常处理都经人工确认 |

免费主机缺扩展、出站、定时任务或足够磁盘时，先解决主机条件。不要删除安全验证或把私有目录改成公开来“适配”。VPS有无面板使用同一程序，区别仅在 PHP/Web/数据库的安装与服务配置。

发布前做一次可验证的备份恢复，保存旧数据库、配置、密钥、文件和版本号。回滚应用不能撤销已经在支付平台发生的收款、退款、代付，也不能收回已下载副本。
