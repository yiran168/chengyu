# 0.20 视觉素材、归档与评论

本版数据库结构 v12，增加可管理的视觉素材与导航图标；现有订单、密钥、内容和上传封面保留。

## 文章归档

前台页脚点击“文章归档”，或访问 `index.php?r=archives`。后台“模块”可关闭归档，“导航”可添加此路由，公告和区块按钮也可指向归档。

输入 `2026` 查看全年，输入 `2026-09` 查看该月。可叠加分类，每页最多 30 篇，按创建时间和 ID 倒序分组。日期边界按站点时区计算，MySQL / SQLite 使用同一时间戳条件。沿用已发布、预约发布、分类祖先及圈子权限，不加载正文和受保护内容；付费文章仍可展示其公开标题/摘要。置顶不打乱归档时间顺序。

## 评论

原版仅显示最近 50 条，现已支持原生分页；最新、最早、只看作者三种排序。采纳回答和置顶优先，同一结果集只出现一次，待审评论不进入统计。阅读权限、评论可见性、模块开关和文章关闭评论均在服务端检查。提交回复后回到最新评论页。没有 JavaScript 时仍可使用排序、翻页和发言表单。

分类卡片现在遵守布局设置中的显示数量。列表、编辑器和卡片共享批量权限判断，一次载入分类关系进行判断，避免每张卡重复查询整个分类表。分类树仍在单次请求中读取，未宣称已经完成十万分类规模压测。

## 虚拟主机

安装页展开“当前主机的 PHP 运行限制”，已安装站点到后台系统页运行能力检测或下载 JSON。会读取内存、上传、POST、输入及执行时间、文件上传开关和输入字段数量。`max_input_time=-1` 按继承执行时间处理；数值解析兼容所有目标 PHP 版本，避免整数溢出。

这些数据来自 PHP，本程序不能据此推断主机账号的实际空间、数据库配额、流量、Web 服务器请求大小或代理超时。检测不会更改主机配置，也不会自动隐藏业务模块。

萌哒云“萌速”的用户截图显示：SSD 2GB、MySQL 1GB、月流量 780GB；面板可选 7.4 / 8.0 / 8.1 / 8.2，截图当前选中 7.4。实际扩展和请求限制需在该实例运行上述检测。更多条件见 HOSTS_AND_SOURCES.md。

## 验证边界

本版通过原生 PHP 七版本各 587 项、HTTP 873 项及真实 Chromium 87 项检查。截图 12 张见 docs/previews/020-*。Windows 无头 Chrome 使用软件渲染以避免宿主遮挡检测冻结帧；没有关闭网站动效或强制触发点击。页面跳转使用 CSS 入场，日夜切换保留同页 View Transition；跨页面快照转场在实际测试中会冻结动画帧，因此已移除。完整证据见 TEST_REPORT.md。

## 后台视觉素材库

在“体验与运营 → 视觉素材库”选择页面位置或界面图标。共有 79 个逻辑图标（73 个代码矢量图标、6 个独立生成的透明二次元图标），可替换为内置二次元图标或上传的公开 PNG/JPEG/WebP/GIF。首页、归档、登录、空状态、页脚、浏览器图标、手机书签分别配置。站标沿用外观设置中的 logo_media_id，避免双重配置。

选内置素材或上传图片即可预览；应用后下一次页面加载生效。普通会员、编辑和审核员不能修改全站素材。服务端重读管理员状态，拒绝私有媒体、可执行 SVG、路径字符串和双来源。并发编辑带版本检查，恢复默认同样拒绝覆盖较新的保存。媒体失效时回到默认设计。

导航、分类和搭建器使用同一份图标目录。添加导航时可选择图标；改动不会等待长时间菜单缓存。内置封面在内容编辑器中选择，已上传图片优先，清空图片 ID 后显示所选内置封面。新装示例的六篇文章各用不同画作。老站不会被批量换封面；没有配置封面的内容显示独立编号的排版占位图，不再循环套用两张插画。

默认“简洁阅读”样式减少英文副标题与装饰，突出真实标题、分类、作者和日期。外观设置可切换“轻盈活泼”。网站已有的自定义文案不会被升级覆盖。页面没有增加虚构点赞量或浏览量。

修复通用上传控件按 name 回填媒体 ID，并触发 input/change，素材预览同步更新。备份白名单包含视觉素材表，恢复时与配置、上传文件一起还原。

按钮波纹现在使用绝对定位，不参与按钮尺寸计算，修复按下后点击区域改变而导致提交失败。支持系统减少动态效果；页面跳转使用轻量 CSS 入场，避免跨页面快照冻结浏览器动画帧。
