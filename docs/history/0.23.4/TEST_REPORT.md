## 实际缺漏和新增覆盖

新增 48 项核心检查、52 项 HTTP 检查；保留原有账户、授权、资金、交易、备份、并发和幂等回归。

- MP4：跳过 300 KiB 前置填充，支持扩展 64 位长度、延伸至 EOF 的数据盒、兼容品牌和初始化段。拒绝品牌头后跟垃圾、越界长度、截断尾部、重复 ftyp 和没有媒体盒的伪容器；模拟超过 4 GiB 的盒偏移时仍只读取少量头部，并验证 32 次额外读取上限。普通上传、分片及 S3 共用检测器。
- PNG：校验 IHDR/PLTE CRC、合法颜色/位深/压缩/过滤/交错字段，索引色必须带合适调色板。全部 15 种颜色/位深组合 × 两交错方式，共 30 个小样本已由独立 Pillow 解码，随后通过 PHP 内容识别和写入；实际 HTTP 覆盖 16 位、索引色和交错图像。
- GIF/WebP：复现小画布内声明超大首帧或编码尺寸不一致仍被接收，修复首帧边界和 WebP 位流尺寸检查。保留正常小帧定位、透明/无损/动画 WebP、渐进式/CMYK JPEG 等样本。异常帧在普通上传、HTTP、S3 均拒绝。
- 分片：同尺寸损坏的内容/防护头、缺失或截断分片均可用原片修复；合并发现损坏后删除对应片记录，浏览器下次获取状态只补传损坏片。HTTP 实际完成损坏、拒绝、取状态、补传、合并、范围下载和重复完成请求的流程。
- 磁盘故障：仅在测试进程注入短写和 fflush 失败，覆盖分片写入、合并防护头/缓冲、媒体落盘。断言先关闭文件再清理、没有媒体记录、可重试分片保留。测试函数不进入生产包。
- 数据库故障：用原生数据库触发器拒绝完成状态更新，验证事务回滚、临时文件/新附件清理及再次完成成功；另模拟两次死锁，验证第三次登记成功且只复制一份附件。
- 云存储：九种受支持格式逐一核对清单、读取范围、ETag、条件复制、私有权限和完成幂等；补充大填充 MP4、坏 PNG/GIF/WebP 和中途变化拒绝，失败只释放自己持有的校验锁。模拟网络等待期间新请求接管，验证旧请求不能覆盖状态、提交媒体或清除新锁；相关两个失败的修改前记录见 before-lease-fix.json。
- 下载：新格式变体保持原字节、附件私有权限、Range、nosniff 和 CSP sandbox；无 Fileinfo 安装流程仍执行安全口令校验。

初轮新用例在修改前复现 8 个失败，见 before-fix.json；另从 v0.23.3 提取旧识别器与最终实现对比六种实际误判，均已修复，见 reproduction.json。这些对照不重复计入最终通过数。

## 验证边界

类型检查不替代解码、播放验证或杀毒。MP4 为容器结构测试；PNG 不解压像素，GIF/WebP 验证首帧而非全部动画帧；大文本只检查有界前缀。格式范围、资源上限与安全存储要求见 FILE_TYPES.md。没有为了识别而调用 Fileinfo、GD、ZipArchive、mbstring、shell 或外部服务。

全部测试使用隔离数据库和测试账号，未连接用户生产数据库。S3 为协议夹具，真实免费主机/VPS、外部支付/SMTP/对象存储未联调。193 张预览及完整 200 项浏览器记录沿用 0.23.0，本版未声称重跑完整视觉套件；本次手册重新生成并验证，见 manual-checks.json。
