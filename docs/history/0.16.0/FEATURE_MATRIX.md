| 内容商业化 | 公开／登录／VIP／付费／回复／密码权限，付费时限，私有附件、配额、Range，作者收益与推荐佣金 | 没有课程学习证明、DRM、圈主分成；作者收益需按条件结算 |
| 商城基础 | 商品、SKU、加密卡密、自动邀请码、库存、购物车、真实购买评价、地址、发货／收货 | 不是多商家市场、多仓管理或可任意组合属性的电商套件 |

## 本版交易增强

| 能力 | 0.16.0 已实现 | 明确限制 |
| --- | --- | --- |
| 访客购买 | 邮箱联系方式、随机私密通行证、订单柜台、收据、购买权限、售后、显式认领到账号 | 邮箱单独不能查询；通行证不自动发邮件；丢失需商家人工核实；会员须登录 |
| 统一结算 | 20 行／100 单位上限，重新计算总额，金额上限、幂等、库存与卡密预留，逐单位订单，共同支付收据 | 仅站点结算币种；积分／代币沿用站内购买；不支持混合支付 |
| 运费 | 固定／按件／按克重量、首重续重、地区覆盖、满额包邮、按模板合并计费和单位分摊 | 地区为商家定义代码；没有地址标准化 API、物流轨迹、面单、关税 |
| 促销 | 满减、比例、每 N 件优惠、买 X 送 Y、阶梯、组合商品；同组择优、不同组顺序叠加 | 优惠作用于当前购物篮，不自动添加赠品；非拼团、拍卖、秒杀排队系统；单张优惠券只支持单单位结算 |
| 售后 | 退款／退货退款／同 SKU 换货，证据、审核、寄回、收货检查、是否可回售、补发单号、收货闭环与修订冲突 | 不含跨 SKU 差价换货、任意部分金额退款、退货面单、实时承运商轨迹、独立多次补发工单 |
| 永久会员与补差 | VIP 1–3、永久套餐；已记录付款权益批次、剩余价值折算、保留到期日或新周期、跨级、永久升级、签名报价、退款回滚保护 | 补差支付走站内资产；不提供任意混合权益套餐；旧批次须核验导入，不自动猜测历史价值 |
| 支付宝 | 官方 RSA2 WAP 下单、验签通知、查单与退款协议 | 非证书模式、Native 当面付或所有产品线；需签约与真实联调 |
| 微信支付 | API v3 H5、请求签名、平台验签、AES-GCM 通知、查单与退款协议 | 非 JSAPI／Native／小程序／服务商多商户；平台公钥与序列号需维护 |
| Stripe | Checkout Session、HMAC 通知、查询与退款、幂等键 | 非订阅账单、多商户分账；须使用可用商户账户和对应币种 |
| PayPal | Orders v2、明确捕获、商户／币种核对、Webhook 验证、退款 | 本版仅数字商品；不允许实物走 NO_SHIPPING；不支持 CNY 自动兑换 |
| 主动对账 | 支付查询与通知共用入账；后台手动、CLI 或签名任务触发；原配置快照 | 是逐单状态核对，不是支付账单下载、银行流水勾兑、会计总账对账 |
| 原路退款 | 四种直连渠道的退款／查询适配、审批、固定退款号、租约、未知状态保留、确认后撤权／回库／账本逆向 | 按一个订单单位全额退款，含该单位分摊运费；真实退款待联调；历史充值不自动退款 |
| 自动代付 | PayPal Payouts：经管理员证明与审核的提现、固定批次号、查询恢复、原来源冻结 | 不包含支付宝／微信企业付款、银行卡代付；不是替别人支付购物订单；需要 PayPal Payouts 权限 |

## 编排、国际化与媒体

| 能力 | 已实现 | 明确限制 |
| --- | --- | --- |
| 中英文 | 顶部／后台切换、会话和偏好 cookie、可选浏览器协商、统一翻译入口 | 站点业务内容、品牌和商家自定义文案不自动翻译；前台／后台共享同一语言偏好 |
| 内容翻译 | 中／英内容版本、人工编辑、修订、发布／草稿、原文变更自动隐藏旧译文、可选 LibreTranslate | 机器翻译需单独服务与明确发送确认，只生成草稿；不发送受保护正文，不承诺免费无限量 |
| 搜索 | 公开标题／摘要／标签与当前有效译文，多词 AND、相关性排序、最新／热门，原有联想与键盘操作 | SQL 检索；没有 Meilisearch／OpenSearch／Elasticsearch、中文专业分词与海量索引验收 |
| 全站插槽 | 22 个位置：四个主列表、全站前后、文章前后、页面前后和 12 个独立页面；11 种区块；人群／会员限制 | 安全结构化编排，不是任意像素自由画布；不可执行任意 PHP／JS／模板；不等于子比全部小工具 |
| 媒体续传 | 管理员 256 KiB 分片、逐片校验、缺片续传、配额、所有权、保护封装、完成幂等 | 本地续传；过期未完成任务需取消；受主机磁盘／执行时间约束；不做转码 |
| 对象存储 | AWS SigV4、私有 S3 兼容存储、浏览器暂存上传、HEAD／Range／类型验证、条件复制到正式路径、短时签名下载 | S3／R2 协议范围；非 OSS／COS 原生 SDK；对象直传为单次 PUT，未实现 S3 多段断点续传 |
| 音视频 | 受控 MP4／MP3 文件、原生播放、媒体区块、本地 Range、对象短链 | 无直播、转码、HLS、DRM、自动字幕和课程学习系统；“大型媒体模块”只完成上传／交付层 |
| 部署与兼容 | 无 WordPress／运行期 Composer／Node／Redis，FTP 虚拟主机、VPS 模板、同一 PHP 7.4–8.5 源码 | 运行环境需扩展和权限；未在两家实机、全部 PHP、原生 PDO／MySQL 验收 |

**仍未完成：**上述边界中列出的全部平台登录、原生 OSS／COS、专业搜索引擎、直播转码／课程、复杂拼团／多仓／承运商接口、账单级对账、支付宝／微信企业付款、全部可视化小工具、完整备份自动化及 WordPress 数据迁移。本包不把这些项目放成空按钮冒充完成。
