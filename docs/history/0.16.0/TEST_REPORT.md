## 先检查，再开发

0.15.0 原核心基线 424/424。先完成结构和旧测试检查，再开发新模块并扩展回归。发现并修复：更新数据库未阻止旧代码启动；访客购买身份可能混入登录视图；会员补差退款需保护之后授予的权益；签到回归；CLI 任务误找根配置而非 app/config.php；签名任务失败状态码未保留；基础 panel CSS 覆盖新侧栏，导致手机结算页偏移。后一项通过截图检查发现并增加文档流断言，不仅看横向溢出数量。

测试脚手架也修正了契约问题：原生私有媒体/密码证明返回 403 而非测试误写的 401；新语言表单使旧“第一个表单”登录选择器不正确；设置更新夹具不得用仅供初始化的 seed；本机 cli-server OPcache 干扰安装配置即时变更，因此仅测试服务器关闭它。减少动态效果的浏览器测试改为等待偏好变化事件再断言清理，而非假设 60ms 内必达，未移除检查或修改生产代码以伪造结果。

## 新功能覆盖

交易测试验证访客私密凭据、认领与隔离，订单/价格指纹与重试，库存/卡密预留，运费与促销分摊，退款/换货状态机、会员残值与永久补差、退款不覆盖新权益。原有库存、账本、优惠券、圈子、投票、收益和身份安全回归继续保留。

四官方支付适配以受控响应和本地生成 RSA/HMAC 密钥验证签名、商户/应用/订单/金额/币种/环境绑定；退款、代付的固定请求号和未知结果处理不依赖假“支付完成”页面。**这些不是实际平台接口连通或资金交割证据。**

真实本机 HTTP 已执行完整站内购买、退款申请、管理员密码审核、重复退款不重复入账、权益撤销、随机访客令牌隔离、实际分片上传/合并/重复完成、译文冲突/审核/搜索防泄漏、规则修订与页面条件、签名 jobs 调用/拒绝重放，以及完整包 tools/run_jobs.php 真实 CLI 命令（测试 PDO 适配器）。

对象存储验证 SigV4/长度/类型绑定、受限 key、私有媒体、CopyObject 条件复制、丢失复制响应后查询恢复、只产生一个媒体 ID。没有真实 S3/R2 桶、网络上传和跨域验收。翻译服务同样没有真实服务商调用；默认关闭并需明确发送公开文本确认。

视觉检查覆盖 320/390/768/1440 宽度、旧主题/动效/键盘/焦点，以及新收银台、访客柜台、交易/运费/售后、媒体/译文、页面编排和中英切换。最终 JavaScript 错误列表为空。不承诺所有设备固定帧率。

## 尚未验收的事项

只有 PHP **8.4.23** 实际可执行；其他六种运行时未验证。7.4–8.5 共用同一功能路径，不意味着七个版本已经认证。14 组 PHP×原生数据库 CI 配置未执行，缺原生驱动会直接失败。

本机没有原生 PDO 驱动/MySQL 服务，真实 SQLite 是经测试专用 FFI 适配器调用。生产仍使用原生 PDO，不要求或推荐用户启用 FFI。MySQL/InnoDB、两家免费主机、VPS 装机、公网证书、正式恢复演练、外部 SMTP/OAuth、四支付商户、退款/代付资金、S3/R2/LibreTranslate 均没有实机通过证据。

浏览器 URL 直接导航受当前环境策略阻止，另有失败记录；set_content 结果不能替代真实浏览器 Cookie/CSP/公网导航/缓存或跨文档转场测试。本地 HTTP 套件是真实请求，但不是来自浏览器导航。不能将这两者混同。
