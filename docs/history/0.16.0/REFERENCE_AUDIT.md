# 0.16 参考源码与公开历史

交付基线为实际上传的 0.15.0 complete/upload ZIP。ICU 三个 RAR 分卷已通过 libarchive 连续读取，共访问 13,652 个归档条目，筛选 827 个主题文本文件供检索；主题 style.css 头声明版本 **7.8**。没有官方发行哈希证明该备份未被修改。

目标核对 action、inc/functions、oauth、zibpay 和设置入口中的会员、订单、访客、支付、退款、推广、媒体/商城定义。827 含 vendor/CSS/JS，不等于逐行审计 827 个业务文件或审计整个旧站。脱敏文件索引仅记录主题相对路径、大小、SHA-256，见 evidence/reference-index-0.16.json。

未执行参考 PHP、导入旧库、使用备份凭证或去除授权；交付不包含参考主题的 PHP/JS/CSS、图片、品牌、截图和字体。业务与界面在本独立工程中编写。哈希差异辅助排除原文件直接复制，不证明零法律风险；自己的素材/授权仍需核对。

## 官方版本对照

官网当前日志标题 V9.1（2026-09-01），本轮取得官方 comment-page-4 搜索正文及首页索引。V1.0–V5.x 的 14960.html 为早期档案入口，本轮正文仍遇超时，不能称重新取得每个早期小版本。没有下载、安装和实测全部历史商业发行包。

| 功能族 | 参考范围 | 本版对应与差异 |
| --- | --- | --- |
| 内容/知识付费 | 早期至 V7.x 内容、下载、模块、会员/媒体 | 独立内容权限、会员、布局与媒体；无 WP hooks/古腾堡/插件 ABI |
| 社区/账户 | V6–V8 社区、邀请、互动 | 问答/投票/圈子/邀请/评价/徽章/安全；非完整圈子付费和时长/次数付费 |
| 商城/售后 | V8.2 以后商城与实物增强 | 总单/单位单、运费/优惠、退货退款/同 SKU 换货；无多仓、跨 SKU 补差、拼团/预售与快递聚合接口 |
| 搜索/国际化 | V8.5 搜索、V8.8–V9.0 多语言/海外支付 | 中英与译文审核、多关键词相关度、四支付协议；无 Meilisearch/ES 和全站自动翻译 |
| V9.0 海外扩展 | 海外登录、Stripe、前后台分开语言 | Google/GitHub/Microsoft 保留；本版前后台共用语言偏好，不含所有社交平台 |
| V9.1 条件/限流 | 抖音、验证码频率、菜单/评论显示条件 | 区块支持访客/成员/VIP，保留验证码限流；不是完整菜单/评论权限规则，无抖音登录 |

本轮补的是交易/会员/售后/媒体/语言/页面编排，不是“子比全部模块”。当前详细功能和缺口以 FEATURE_MATRIX.md 为准。
