## 0.23.4 保留修复

MP4 按盒长度跳过大填充区，支持 64 位长度和延伸至文件末尾的数据盒，校验顶层盒边界。PNG 增加 IHDR/PLTE 的 CRC 与格式组合检查；GIF/WebP 增加首帧尺寸一致性检查。分片重传校验实际字节，合并发现损坏后清除损坏片记录，使界面重试能补传；写入与刷新失败先关闭再清理。媒体落盘位于数据库重试之外，登记和完成状态原子提交，失败清理孤立文件；云端校验提交和释放锁均核对归属，防止过期请求影响接管者。

## 0.23.3 保留修复

JPEG 类型与尺寸在所有上传入口共用单次有界检查，可跳过大附加信息；支持空 ZIP64，ZIP 注释中的伪结束记录不再中断正常查找；PK/RIFF/ID3 开头的普通文本不再仅因前几个字母误拒绝。GBK/GB18030 文本保持私有下载和原始字节。新增真实编码器图片变体与上传回归。

## 0.23.2 保留修复

安装和上传不再依赖Fileinfo；九类允许文件共用有界内容检测，维持图片限制和附件私有权限。S3补充范围、版本和尾部校验，安装器按失败项给出处理办法。详见FILE_TYPES.md与TEST_REPORT.md。

## 0.23.1 保留修复

凭据按输入原值校验并加密保存；空密码保留、明确清除语义不变。安装器 MySQL 密码使用相同校验。前台指定编辑目标不存在时返回 404，不再误开新建表单。结构 v15 与既有模块不变，详细验证见 TEST_REPORT.md。
