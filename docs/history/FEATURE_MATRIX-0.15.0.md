# 功能覆盖与差异清单

版本 0.15.0 / 2026-09-06。本表按功能族列出独立实现，而不是把子比每个设置项、每个历史版本或付费插件逐一等价认证。“实现”指存在可调用的业务代码与管理入口，不等于真实商户、真实主机或独立安全认证已通过。

## 内容、社区与用户

| 功能族 | 本版范围 | 边界 |
| --- | --- | --- |
| 独立站点与管理后台 | PHP/PDO、中文前后台、实体 `/admin`、安装向导 | 非 WordPress，不兼容原主题数据库与插件 |
| 文章、帖子、页面 | 分类、标签、摘要、Markdown、封面、置顶、精选、审核、展示时间 | 非古腾堡/富文本短代码全集 |
| 投稿 | 普通投稿＋获准作者付费文章/帖子、受保护正文、审核、旧管理员定价保护 | 不是自助经营任意商品；普通作者私有文件/视频上传未扩权 |
| 作者收益 | 余额内容订单、扣推荐佣金后的比例、等待期快照、结算、退款冲回、独立收益资产 | 非圈主/积分/代币分成；不是自动结算或外部托管 |
| 创作中心与管理 | 本人统计/明细/结算，后台全体明细、作者批准和独立比例，来源隔离的人工提现 | 每次结算最多 50 条；外部打款需人工与真实对账 |
| 内容权限 | 公开、登录、VIP 分级、付费、回复、密码；VIP 免费规则 | 必须按内容自己的规则授权，不是 VIP 自动全站免费 |
| 付费有效期 | 新订单快照、永久或 1–3650 天、到期后可重购 | 不追溯缩短旧单；不是课程学习进度 |
| 密码与修订 | 哈希密码、错误限流、会话授权；最近 20 个文本修订与冲突保护 | 不能防止授权用户传播密码；修订不回退财务 |
| 私有附件 | 权限判定、下载流水、用户日额度、单段 Range、HEAD | 不是对象存储/CDN 私有令牌；匿名密码访客无身份日配额 |
| 社区 | 版块、主题、评论/回复、审核、置顶、举报 | 复杂版主权限与完整社交动态生态 |
| 分类继承 | 8 层树、父子同类型、阅读和发布权限独立、祖先条件叠加 | 无按经验等级/认证身份的完整细粒度策略编辑器 |
| 圈子 | 免费/余额/积分/代币加入、按期限授权、成员管理、退款撤权 | 非定期扣款；到期重购而非提前续期；无圈主分成/复杂角色 |
| 积分悬赏 | 问题托管、采纳结算一次、过期领取退回、管理员退回、审计 | 无现金悬赏、多人分奖、追加悬赏或自动定时退款 |
| 问答与单/多选投票 | 问答采纳、审核撤销、最多 10 选项、限选数量、一账号一票、截止/隐私、旧票迁移 | 不允许投票后改票；账号唯一不等于自然人唯一；没有实名防刷保证 |
| 社交与通知 | 点赞、收藏、关注、私信、站内通知、榜单、关注作者内容流 | 没有 WebSocket 或完整社交动态生态 |
| 私有阅读历史 | 本人记录/进度、单条删除/清空、个人关闭并清空、站点容量限制 | JS 尽力提交；非课程证明/自动精确定位；后台不提供任意用户历史查看 |
| 搜索联想 | 公开可展示元数据、6 条建议、200ms 防抖、IME/过期响应保护、键盘操作 | 非隐藏正文搜索/Meilisearch；大规模性能需要专门验收 |
| 用户中心 | 资料、头像、钱包、订单、地址、会员、投稿与消息 | 人工认证标记不等于法定实名核验 |
| 密码登录与找回 | 会话保护、限流、SMTP 重置令牌 | 本地 TLS SMTP 协议验证通过，外部服务未联调；无短信；可选 TOTP 由独立安全中心管理 |
| 账户双重验证 | 6 位时间型验证器、8 个单次恢复码、重放保护、轮换/解绑、撤销其他会话、本人审计 | 无短信/WebAuthn/强制全员策略；密钥手动输入，无远程二维码；丢失全部证明需站点所有者本地恢复 |
| 邮箱证明 | 验证码注册/改绑、用途/会话绑定、单次消费、限额、错误次数、旧找回链接失效 | SMTP 默认关闭；须自己的可用服务；邮箱验证不是实名认证 |
| 邀请注册 | 批量代码、摘要存储、次数/到期/停用、注册原子扣次数 | 手工生成明文只显示一次；自动销售是独立商品类型，需邀请码注册模式 |
| 任务中心 | 一次/每日、签到/评论/文章/资料证明、积分与经验、原子领取 | 非外部平台任务；无自动定时领奖或复杂等级权益引擎 |
| 专题 | 后台编排内容、前台集合页 | 基础专题，不是任意多层自动聚合与多维筛选引擎 |
| 友情链接与公告 | 分组/排序/启用、安全链接、公告时段与人群 | 不自动审查外站；展示时间判断不等于 cron 作业 |

## 会员、资产、交易与商城

| 功能族 | 本版范围 | 边界 |
| --- | --- | --- |
| 会员 | VIP 1–3、独立期限、同级续期、高级包含低级访问 | 新增 0 天套餐的永久权益；无升级补差或复杂权益包 |
| 余额/积分/代币 | 整数账本、签到/连签、奖励、消费、兑换、流水、后台调账 | 站内代币不是链上资产，不承诺投资回报 |
| 用户转账 | 可选开启、身份/额度/幂等保护 | 经营者需自行判断合规，不是银行转账 |
| 兑换码 | 资产或基础会员天数、过期与一次性兑换 | 不等于任意复杂营销券包 |
| 易支付 | 经典托管收银台 MD5 协议、异步通知、配置快照、去重与校验 | 待真实商户联调；不覆盖所有同名平台、RSA V2；已有经典协议充值按需查单 |
| 旧 CodePay | 旧式字段实验性兼容适配 | 默认关闭，未确认原服务可开通；不支持浮动金额模式 |
| 支付链路 | 外部充值余额后站内购买 | 无所有商品直接外部网关付款/混合支付的完整闭环 |
| 购买一致性 | 请求键与指纹、事务、重复通知防护、库存与权益处理 | 未在真实 MySQL/生产并发环境验证 |
| 数字资源 | 内容/附件购买与授权、有效期、退款撤权 | 合法下载到用户设备后不可收回副本 |
| SKU | 实物/卡密多规格，独立价格、库存、启用和排序 | 最多 100 个；不是复杂属性组合生成、规格图片继承或多商家入驻 |
| 卡密 | 加密、导入、去重、按规格自动发货、剩余量同步 | 已发码不再次出售；自定义卡密仍由管理员导入 |
| 自动邀请码商品 | 订单内生成、摘要验证、加密交付、次数/期限、未使用退款停用 | 已使用拒绝自动退款；仅单规格；已交付不回售；需邀请码注册模式 |
| 商品评价 | 真实订单校验、1–5 星、文字、审核、退款后排除公开评分 | 无图片追评、商家回复、评价奖励或虚构销量 |
| 实物 | 地址、库存、人工发货、运单更正、确认收货 | 无运费模板、物流查询、售后寄回、价保的完整流程 |
| 购物车 | 按商品+规格分条、整车原子结算、重复请求保护 | 条目/数量有限制；无访客结算或跨店业务 |
| 会员与活动价 | VIP 1–3 比例、高级继承低级优惠、限时价择低、每 SKU 同算、版本冲突保护、订单快照 | 非固定绝对会员售价、升级补差、秒杀库存预占或阶梯量价 |
| 优惠券 | 固定/比例、范围/指定内容/开始结束/最低会员、单账户一次、配额原子核销；可选与特别价叠加 | 仅余额且一次一张；默认不叠加特别价；无多券/赠品/复杂促销 |
| 报价确认 | 服务端初始价、实时试算、旧响应失效；单件表单最高确认额拒绝静默涨价 | 不锁价/留库存；现有整车三资产分别上限与整单回滚；无 JS 的规格变化没有同等上限同步增强 |
| 退款 | 支持的站内购买退原站内资产、符合条件的原规格回库、圈子权益/未用邀请码逆向 | 无自动外部原路退款；充值与会员退款不是自动路径；已使用邀请码转人工处理 |
| 推荐佣金 | 单级推荐、比例、流水、退款冲销、可选开启 | 与新增作者收益独立记账；不是多层分销 |
| 提现 | 推荐佣金/作者收益来源选择、冻结、审核、原来源释放、退款负收益阻止确认 | 人工外部转账；已提现后退款仍可能形成内部负债，无法自动追回外部款项 |

## 外观、运营与基础设施

| 功能族 | 本版范围 | 边界 |
| --- | --- | --- |
| 主题 | 5 种视觉主题、明/暗/跟随系统，共用业务组件 | 原创表达，不是原子比像素级复制 |
| 玻璃与动画 | 4 档玻璃（含关闭）、5 条预置曲线＋自定义、时长/悬浮/涟漪/显现/背景/进度等 | 依赖浏览器能力；减少动态效果时主动收敛 |
| 动效工作台 | 三套预设、36 项动效参数、贝塞尔与物理弹簧图、速度连续指针响应、灯光/透视/磁吸/扫光/视差/主题转场 | 预览保存后生效；依浏览器能力增强，不是 3D 游戏引擎 |
| 交互细节 | 连续反向折叠、移动焦点约束、灯箱、分享回退、导航跟随线、可关闭通知、表单/搜索/图片反馈 | 浏览器能力渐进增强；灯箱不绕开媒体授权；新增连续布局重排/键盘焦点保持/0ms；没有生成社交海报 |
| 阅读目录与专注布局 | 仅依据授权输出标题生成目录；可选隐藏侧栏的专注阅读，保留正文/购买 | 无课程学习进度、云笔记或收藏段落 |
| 新视觉选项 | 三种首屏装饰、舒适/紧凑密度、低资源视觉优化 | 不通过减少业务功能来降低负载 |
| 后台设置 | 192 项 / 13 组，业务对象专门管理 | 不是每段固定文案和所有代码行为都可后台编辑 |
| 布局工作台 | 4 个位置、8 种组件、24 块上限、排序/复制/导入/导出/模板 | 结构化编排，非全站自由画布/完整所见即所得 |
| 后台业务 | 用户、角色、内容、分类、套餐、订单、库存、卡券、财务、媒体、导航、审核、审计、系统 | 不属于主机管理面板 |
| 搜索与 SEO | 基础可见标题/摘要/标签搜索、元信息、OG、RSS、sitemap、noindex | 无 Meilisearch、AI SEO、全站智能多语言 |
| 媒体 | 图片及受限资源类型上传、大小/MIME、授权输出 | 无云盘代理、对象存储、视频转码/直播 |
| 统计与清理 | 数据库计数、订单、下载和审计查询；受限维护清理 | 无完整流量分析平台、业务智能报表 |
| 数据库 | MySQL/SQLite 两方言代码、增量结构 v7 | 本次真实 SQLite 测试；原生 PDO/MySQL 未验收 |
| 部署 | 共享主机文件上传、面板 VPS 模板、新 VPS 脚本 | 必需扩展、权限、HTTPS 仍需主机提供 |
| 主机自检 | 管理员按需检测扩展、原生驱动、加密、绑定/回滚、存储；脱敏 JSON 下载 | 非全版本全模块认证；不探测公网目录/真实支付/邮件/证书，不改变主机权限 |
| 证书 | VPS Caddy 自动 HTTPS 的部署配置 | 不是 PHP 在任意免费主机上自动申请、安装、重载、续期 |
| 备份恢复 | 一致性备份/手工恢复说明、升级与回退说明 | 无后台自动备份平台和自动降级 |
| 开发扩展 | 服务层、字段定义、共享视图、回归测试、CI 文件 | 无 WordPress 插件 ABI、插件市场、在线热更新 |

## 0.15 新增功能与限制

| 功能 | 已实现 | 边界 |
| --- | --- | --- |
| 第三方登录 | Google / GitHub / Microsoft，授权码、PKCE、显式绑定、本地注册规则与第二因素 | 不按邮箱合并；无 QQ/微信/抖音/Apple 等其他驱动；真实应用待联调 |
| 主动查单 | 易支付充值订单按需查询，原配置快照，与通知共用入账 | 非全量定时对账、CodePay 查询、网关退款或代付 |
| 配置快照 | 加密、最近 30 份、导入导出、脱敏差异、恢复前备份、修订冲突保护 | 仅集中设置，不是整站备份；需原站密钥 |
| 社区徽章 | 创建、授予、到期、撤销、展馆、个人展示 | 纯荣誉，无自动任务发放或权限捆绑 |
| 后台分组与图标动效 | 搜索自动展开/恢复、键盘入口、有限次动画清理 | 共用曲线与降低动态效果策略；不保证所有设备固定帧率 |

## 尚未补齐的关键方向

其他第三方登录与短信/WebAuthn；升级补差和复杂会员权益；圈主经营分成、复杂成员/版主角色、自动徽章规则；现金悬赏、多人分奖；作者分成的更多资产与会员策略；访客购买；更复杂 SKU、促销、运费和退换货；官方支付宝/微信直连、Stripe/PayPal、全量定时对账、网关退款与自动代付；全站自由搭建、智能多语言、专业搜索；大型媒体/课程/直播与对象存储；主机面板证书 API；完整备份自动化及 WordPress 数据迁移。

这些缺口没有用空按钮或假数据标成“已完成”。参考历史记录用于检查功能族，**并未逐一取得并安装所有历史发布包**。历史档案取得情况和源码取样范围见 REFERENCE_AUDIT.md。
