## 本轮怎样使用核对结果

避免重复重写已有结算/会员代码：新增课程直接继承当前权限，物流关联当前实物单位订单，账单核对只读现有收据和退款记录。新页面统一经过现有CSRF、身份、限流和模板系统；英文翻译仍使用同一个语言入口。代码路径与操作说明见 `PLATFORM_017.md`。
