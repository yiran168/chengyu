# 澄屿 Chengyu 0.17.0

独立 PHP 内容、社区、交易与学习网站。以用户上传的 **0.16.0 完整包**为基线继续开发，数据库从 v8 增量迁移到 **v9**。不依赖 WordPress，不包含 ICU 商业主题源码、原站数据库、图片、字体或商户凭据。

## 先读这里

在本地打开 `START_HERE.html`。新站看 `docs/DEPLOYMENT.md`；已有站点先看 `docs/UPGRADE.md`；本轮新功能的操作步骤在 `docs/PLATFORM_017.md`，全部能力与边界在 `docs/FEATURE_MATRIX.md`。本版不是全部子比历史版本、设置项与第三方插件的完整等价实现。

完整包供本地保存，仅上传 `site/` 内的内容，或使用单独的 upload ZIP。不要把完整包、测试、备份、安装口令或数据库放在公开目录。新站安装口令在完整包的 `INSTALL_KEY.txt`。已有站点保留原 `app/config.php`、其中的 `secret`、数据库和全部 `storage/`，不要重新安装。

## 本轮主要变化

- 搜索升级为可分批重建的公开元数据倒排索引，支持中文相邻字词、英文词、多词组合、相关度排序，原文修订与译文状态联动；未完成重建时沿用旧搜索。
- 页面编排增加独立草稿、显式发布、最近 20 次历史与恢复、多人编辑冲突保护；草稿不会修改线上页面。
- 新增课程、章节、预览、私有资源、个人进度与笔记，复用现有内容购买、会员和有效期权限；退款、下架或撤权会重新校验。
- 新增加密物流轨迹、手工更新、快递100查询适配和查询限流。轨迹不自动确认收货、不触发资金操作。
- 新增标准化账单 CSV 导入、双向差异核对与重复导入保护，只生成核对报告，不根据上传文件入账或退款。
- 新增前后台客服工单、回复模板、通知、状态与优先级、幂等和权限隔离。
- 前台、后台语言偏好分开保存；支付宝增加可选择的电脑网站支付模式；统一导航白名单与新版响应式工作台。

修复访客影子账号被计入社区人数、列表译文过量读取正文、Windows 媒体失败清理顺序、页面 canonical 丢失编排位置等问题。新增功能走现有权限、CSRF、数据库事务和服务层，不另造一套资产或权限系统。

## 运行和验收

64 位 PHP 7.4–8.5 共用同一套功能代码；生产使用原生 PDO MySQL 或 PDO SQLite、OpenSSL、Fileinfo 与可写私有存储。不要求运行期 Composer、Node、Redis、SSH、FFI 或常驻进程。外部支付、邮件、翻译、对象存储和物流接口需要自己的服务账号、HTTPS/TLS 出站权限及真实联调；自动任务仍需可靠的调度触发。

本轮实际 PHP 为 8.4.23，数据库测试使用测试专用 FFI 接入真实 SQLite，不是原生 PDO/MySQL 验收。没有把未执行的七版本 × 两数据库 CI、两家免费主机实机、真实商户和云账号列为通过。测试报告包含实际方法、失败修复记录和未测边界。

## 交付体积

部署源码、压缩后上传包、测试、说明和截图分别统计于 `RELEASE.json`。没有通过复制商业主题、打包未用依赖、重复代码或无关图片凑到 5 MB。文件体积不是功能完成度的证明；未完成项不会因为压缩包变大而消失。

源码入口 `site/index.php`；后台 `site/admin/`；安装器 `site/install/`；部署模板 `deploy/`；测试 `tests/`；校验清单 `FILE_MANIFEST.sha256`。
