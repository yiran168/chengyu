# 0.17.0 功能覆盖与未完成项

日期：2026-09-07；实际基线：用户上传的澄屿 **0.16.0**；数据库：**v9**。这是独立程序的能力清单，不是所有子比历史版本的等价认证。代码测试与真实平台联调是不同状态，见 `TEST_REPORT.md`。0.16 原报告保存在 `history/0.16.0/`，仅供追溯。

| 外观与运营 | 五主题、明暗/跟随系统、玻璃层、弹簧/贝塞尔动效实验室、键盘焦点、目录/专注阅读、专题、任务、公告、链接、导航、加密配置快照 | 不保证所有设备固定帧率；配置快照不是整站文件及数据库备份 |

| 售后 | 退款、退货退款、同SKU换货、凭证、审核、寄回、验收、回库、补发及版本冲突保护 | 无跨SKU补差、任意部分金额退款、独立多次补发、退货面单 |

| 支付宝 | RSA2 WAP；**0.17 新增 PAGE 电脑网站支付**；共用查单、通知验签、退款 | 非证书模式/当面付/所有产品线；真实签约和商户待验收 |
| 微信支付 | API v3 H5、签名/平台验签、AES-GCM通知、查单及退款协议 | 无JSAPI/Native/小程序/服务商多商户；真实联调与密钥轮换由部署方验证 |

| 逐单查单/退款 | 后台、CLI或签名调度；审批后固定退款号、租约、未知状态保留、确认后资产及权限回滚 | 单订单单位全额；历史充值不自动原路退；需要真实调度 |
| 自动代付 | 审核后的 PayPal Payouts、固定批次、状态查询和原来源冻结 | 无支付宝/微信企业付款、银行卡代付；不是代替顾客付购物单 |

## 仍未覆盖的差距

不能把以上“有限实现”扩大成“全部子比模块已完成”。仍缺：全部官方/第三方社交登录与短信渠道、完整验证码六维可配置限流、专业外置搜索引擎、全部可视化小工具、任意画布、原生OSS/COS、直播/转码/HLS/DRM、跨SKU/部分退款、多仓/面单、拼团/拍卖/秒杀排队、原始账单自动下载及完整财务对账、支付宝/微信企业付款、完整自动化备份、WordPress数据迁移等。

历史版本对照见 `HISTORICAL_FEATURES.md`，参考源码审阅方式见 `REFERENCE_AUDIT.md`。未实现功能没有添加假成功按钮或空驱动宣称可用。
