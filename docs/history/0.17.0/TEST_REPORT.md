## 数据库、运行时和浏览器边界

本机只提供PHP **8.4.23**，没有可用原生pdo_mysql/pdo_sqlite及MySQL服务的完整测试条件。FFI适配调用真实libsqlite3，能执行SQL、事务和并发测试，但**不等于原生PDO驱动或MySQL/InnoDB验收**。生产仍只用原生PDO；不上传测试适配器，不要求用户主机开FFI。

七PHP版本×两原生数据库共14项CI配置在 `.github/workflows/php.yml`，本轮未执行。CI缺原生驱动会失败，不会用FFI回退冒充原生通过。应用没有按PHP小版本减少功能，但同源码目标不能代替实际逐版本执行。

真实浏览器URL导航尝试被环境策略阻止，证据在 `evidence/live-browser-0.17-blocked.json`。离线浏览器不验证公网TLS、完整Cookie/CSP资源加载、Web服务器规则、浏览器支付跳转或真正跨页面转场。HTTP套件的私有目录阻断由测试路由提供，不证明Apache/IIS/Nginx/Caddy配置在真实主机生效。
