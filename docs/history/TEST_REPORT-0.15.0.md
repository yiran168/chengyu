## 先复现，再修复

0.14 基线为 339/339。加入三条安全边界后，342 项中出现三项失败：撤销中的旧会话仍可修改密码；密码二次确认可能接受超长输入的 bcrypt 截断；停用账户仍可使用缓存资料对象修改个人信息。事务内重新读取账户、状态、会话版本，并统一密码字节上限后，342/342 通过，再继续扩展模块。

新功能开发中的失败也留有记录：测试误用设置分组名、会员期限字段名及报价参数名；Microsoft 测试先使用缩写 scope，校正为服务端与官方文档一致的完整 URI。这些不是把失败项删除，而是修正测试契约后保留并完整重跑。

浏览器起初有两项图标动画断言失败。独立复现发现重复 set_content 保留旧文档/媒体监听器，干扰了减少动态效果切换。动效检查改为新的浏览器页面上下文，并等待媒体偏好传播，再验证启动、完成、0ms、减少动态效果、低资源和 pagehide 清理；两项断言仍保留。没有用删测试换通过。

几次长测试达到工具时限或被中止，未产生完整 JSON，不计入通过。最终以完整 JSON、退出码及 stderr 检查为准；核心 stderr 为空。

## 身份连接与 HTTPS 传输

Google、GitHub、Microsoft 的授权码请求使用受控协议响应夹具，检查授权 URL、state、PKCE、令牌交换、Bearer 用户信息、稳定 subject、本地绑定/登录/注册和不存访问令牌。测试验证不同邮箱或同邮箱都不会自动附着旧账户、第二因素不能绕过、撤销后的旧证明失效、相同身份不能绑定两个账户、关闭新登录后仍可本地解绑。

三家平台**没有使用真实应用完成公网跳转联调**；协议夹具不是远端 HTTP/TLS 成功证据。新 HTTPS 传输检查非公网地址、危险 URL、超长响应、截断、重定向、重复 Content-Length、冲突传输头、分块格式和非法 JSON。真实主机的 DNS、CA、443 出站与服务商策略仍需验收，不能因为解析器通过就宣称网络链路通过。

生产不使用这些假响应，不会通过“演示登录”替代服务商认证。应用不按邮箱自动合并身份，不保存 OAuth 访问令牌，也不把解绑当作远端撤销授权。

## 主动查单与交易幂等

检查订单所有者/管理员权限、网关同源、原始加密配置、商户/订单/渠道/金额/status、错误响应不入账、超时后的合法充值、重复查单及冲突凭据。通知与查单共用实际入账服务。

**四个查单进程与四个合法通知进程同时处理同一充值单，最终只入账一次、只有一条入账审计。** 查单返回值中的 changed 表示本次是否真正改变账本，不会因为最终状态已支付就误称本次重复入账。

这只是本地协议、SQL、约束和事务验证。没有真实商户充值、资金结算、原路退款或自动代付。手动调账也不是商户收款事实。

## 永久会员、整车上限、快照与徽章

永久会员验证 0 天套餐的明确永久哨兵、三个等级独立、续加有限天数不缩短永久期限、已拥有同/高等级永久权益时阻止重复收费，以及请求重放返回原订单。

整车结算验证余额/积分/代币三个独立上限、价格上涨或币种变化后的拒绝、无订单/扣款/库存残留和正常结算。价格上限不是保留库存或任意改低服务端售价。旧版未发送上限的自定义表单不能自动获得这项确认保护。

配置快照验证密文、不泄露密钥的预览、导入类型/大小/站点密钥绑定、30 份保留、恢复前备份、版本冲突、失败回滚、管理员范围及密码/第二因素证明；真实 HTTP 包含附件下载与 multipart 导入。仅集中设置，不是数据库/媒体/布局全量备份。

徽章验证管理员创建/授予/撤销、重复操作幂等、到期/停用账户隐藏、非法图标拒绝、无额外权限。**八个进程授予同一用户同一徽章，只形成一条授予记录和一次对应通知。** 原有库存、投票、圈子、悬赏、收益、恢复码和优惠券并发回归全部保留。

## HTTP、邮件与浏览器

544 项 HTTP 覆盖安装、CSRF、会话、角色、各旧模块以及新增连接页面、错误 state、徽章、加密快照、恢复冲突、永久套餐实际购买、整车上限回滚、菜单唯一入口、v7 迁移和服务器异常扫描。没有将浏览器模拟 fetch 算作真实服务端交易。

既有本地 TLS SMTP 夹具继续验证验证码注册/改绑；临时自签信任仅在隔离进程。外部邮箱服务商未联调。

316 项离线交互包括新增页面在 320/390/768/1440 宽度无横向溢出、搜索展开并恢复导航组、Alt+/、Escape、原生键盘折叠、移动菜单焦点、有限图标动画、敏感下载使用原生表单及注册共用字段。新页面与旧页面使用同一主题、曲线、时长和减少动态效果设置。

截图来自隔离站点原创示例与实际生成的数据，测试平台 ID/密钥只是明显的占位内容；不是生产平台接通证明、实际营业额、原主题截图或概念海报。未测固定帧率基准，不承诺所有设备 60/120 帧。

本轮再次直接运行真实 URL 浏览器入口，localhost 导航仍被策略阻止；没有绕过限制。set_content 结果不能证明浏览器公网导航、Cookie、CSP、缓存、反向代理或跨文档转场成功。

## PHP 与数据库验收边界

实际只有 **PHP 8.4.23**。PHP 7.4–8.5 没有按版本移除模块，仍运行同一业务代码；但另外六种运行时本轮未取得执行证据。CI 文件是配置，不是七个版本的认证报告。

本环境无原生 PDO MySQL/SQLite 驱动，测试适配器连接真实 libsqlite3，可以验证真实约束与事务，但**不是原生 PDO 或 MySQL/InnoDB 验收**。生产仍使用 PDO，不需要虚拟主机启用 FFI。14 组 CI 缺驱动直接失败，不允许回退后报告原生成功。

两家实际主机、其他运行时、MySQL、三家 OAuth、外部 SMTP、真实商户、VPS、公开证书、生产恢复演练都没有本轮实机通过证据。
