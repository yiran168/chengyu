# 0.22：分层导航与文章图片

本版继续使用独立 PHP、原生 PDO 和现有模板，不需要 WordPress、Node 服务或常驻进程。同一套功能代码用于 PHP 7.4–8.5。

## 后台导航

打开后台「导航」，新建或编辑菜单，可以设置父级、目标栏目、图标、公开图片、说明、顺序和可见人群。最多三层、500 条记录；父菜单停用或仅会员可见时，子菜单一起遵循限制。桌面显示前五个一级入口，其余放进「更多」。手机菜单和关闭 JavaScript 后的导航也使用同一棵树。

一级菜单可以选紧凑下拉或两栏。带子项的菜单点击展开，其中「进入栏目」打开父项的目标。Enter 和空格可以展开，Esc 收起当前菜单，点击外部收起桌面菜单。图片和说明显示在下拉区及手机菜单，避免把页头挤满。

编辑时使用修订号防止另一个窗口的旧内容覆盖新修改；当前表单的新建请求可安全重试。服务端拒绝循环、孤立父项和超过三层的移动，包括移动整个子树。菜单隐藏只是导航展示规则，目标页面仍执行自己的访问权限检查。

## 正文插图与多图列表

文章编辑页展开「插图与多图排版」，上传公开图片、填写说明，点击「插入公开正文」。按钮把 `![说明](media:123)` 插在正文光标处；最后保存文章才会发布文字修改。没有 JavaScript 时也可填写已有图片 ID 和这段语法。

正文图片支持原有大图查看器，说明作为替代文字并可显示在图片下。后台「阅读排版」可关闭图片说明或自动多图列表。代码块和行内代码里的图片语法保持文字。

文章列表可单独选择「跟随站点、单图、多图、纯文字」。多图位可选择两到四张不同的公开图片；全部留空时，在保存时提取公开正文前四张有效图片。受保护正文不会被拿来生成公开列表。图片不足两张时使用原有单图规则，商品图不受文章开关影响。

删除图片或改为私有后，每次公开请求都会重新检查媒体状态。列表批量读取图片记录，避免每张卡片各自查询。正文只引用本站媒体，不自动抓取外站图片；大文件可在上传前缩小尺寸，以节省免费主机空间和流量。

## 图标与动效

本版增加独立生成的相机图标 `anime-gallery`，共 81 个逻辑符号、其中 8 个独立二次元图标。后台「视觉素材」可以为每个逻辑符号替换上传图片、选择内置素材或恢复默认。菜单也可直接指定自己的图片，不要求复用封面。

下拉菜单采用短距离淡入，沿用后台曲线与时长，并遵循系统「减少动态效果」。菜单不使用折叠区的高度动画，避免外部关闭与展开动画争抢状态。网站正文、编辑表单、列表与移动导航都保留原生链接和表单。

## 升级和范围

数据库结构升级到 14：原菜单保留为一级，文章保留原有封面和文字，新增多图字段为空。旧文章不会批量扫描，编辑保存后才提取公开正文图片。请按 [升级说明](UPGRADE.md)保留配置、数据库和上传内容。

本版补齐了三层手动导航、图片菜单与本地文章多图；没有实现自动填充分类文章的巨大菜单、外站图片采集或第三方主题全部历史插件。实际主机的扩展、上传限制和目录保护以安装检查与后台诊断为准，见 [主机说明](HOSTS_AND_SOURCES.md)。
